# 做过 Agent 吗

## 30 秒版

没有，这是明确的空白，不编。相关的是工具调用式的设计——按任务路由到不同模型或服务——但没做过模型自主决定调哪个工具的闭环。

## 展开

- 分清两件事：人决定调哪个服务（我这半年做的），模型自己决定调哪个工具（没做过）
- 我知道的边界：ReAct 循环、工具描述设计、失败重试与终止条件，能讲原理，没跑过生产
- 补齐路径：MCP Server 一天能做完，先有个可演示的东西

## 我的数字

- Agent 闭环 0 个
- 路由式调用有：2 家 provider、3 类任务

## 追问预演

- **Q**：那你怎么理解 ReAct？
  **A**：推理 → 调工具 → 观测 → 再推理，靠终止条件收口。难点不在循环，在工具描述和失败处理——描述错了模型就调错。
- **Q**：多久能上手？
  **A**：我做过完整的任务路由和降级，缺的是让模型自己决策这一步。给两三周能做出能演示的闭环，做稳要更久。
