# Redis 在这个项目里用来做什么

## 30 秒版

这个项目里 Redis 不是业务缓存，主要放会话态：会话与令牌、验证码、WebSocket 票据、计费计时。所以被问缓存穿透、雪崩时，我如实说这个项目没做业务缓存，Redis 用在了状态上。

## 展开

- 四类键：TokenStore、SessionStore、验证码、建连票据，另有一组计费计时
- 为什么不拿它做业务缓存：这个项目的读热点在会话上，业务数据量不大，直接查库更快也更简单
- 知道但没做的：缓存穿透（空值缓存 / 布隆）、雪崩（过期打散）、热 key —— 说出来但别装作做过

## 我的数字

- 4 类会话态键 + 计费计时
- 业务缓存 0 处（如实说）

## 追问预演

- **Q**：那如果让你加业务缓存，怎么做？
  **A**：先看读写比，再定 key 粒度；穿透用空值缓存或布隆兜，雪崩给过期时间打散，热 key 走本地缓存加多副本。没做过但要能说清思路。
- **Q**：Redis 挂了会怎样？
  **A**：会话和票据全断，用户要重新登录并重建连接。所以 Redis 上只放「丢了能重建」的状态，业务事实一律落库。
