# 2023 年才转 Java 为什么现在投后端

## 30 秒版

2023 年起在筱沅做服务端，2026 年 2 月起独立负责 PassUp 后端，从建表、接口到部署全部自己来。后端仓库 398 次提交，其中 382 次是我，721 个类、47 个迁移、677 个单测。不是我前端干不下去，是这几年一直在往服务端走。

## 展开

- 事实、证据、落点三段，别绕
- 被追问 2023-2025 在做什么：那段时间同时负责小钉贴的前端架构，2026 年起重心完全转到后端
- 落点：前端经历让我更清楚接口该怎么设计才好用

⚠️ 不要主动说「那三年在做前端」，但被问不能否认。

## 我的数字

- 398 次提交，382 次作者是我
- 721 个类 / 6.3 万行 / 60 个接口控制器 / 47 个迁移 / 677 个 `@Test`

## 追问预演

- **Q**：半年后端经验，凭什么比应届或三年后端强？
  **A**：不比谁强，比的是能一个人打通链路。同一套需求，我不需要前端来找后端对齐三次，接口第一版就按可用性设计。
- **Q**：那 2023-2025 你到底做什么？
  **A**：小钉贴的前端架构，五端。岗位挂 Java，服务端和 AI 接口也在这个岗位下，所以我没闲着，但主责确实是前端。
