# 越权为什么返回不存在而不是 403

## 30 秒版

403 等于告诉对方「这条记录存在，只是你没权限」，可以被用来一条条探测数据。所以「不归你」和「不存在」返回同一个结果。加分点是知道公开端点会跳过 Token 解析，往这类接口里加用户态字段会静默恒为 null。

## 展开

- 信息泄露的角度：状态码本身也是信息，403 与 404 的差异就是存在性探测的入口
- 实现上怎么统一：越权判定在数据层做，查不到就统一抛 NOT_FOUND
- 代价：排障时要靠日志区分「真不存在」和「无权」，不能靠状态码

## 我的数字

- 越权与不存在统一返回 `NOT_FOUND`
- 这条写进了 AGENTS.md 的跨模块不变量：越权返回 404 而非 403

## 追问预演

- **Q**：那怎么区分两种情况的日志？
  **A**：接口层不区分，日志里区分。打点时带上「查无此记录」和「存在但归属不符」两种原因，对外都是 404。
- **Q**：公开接口怎么办？
  **A**：公开端点跳过 Token 解析，用户态字段会静默为 null。需要单独的可选鉴权分类，不能靠「有没有登录」猜。
