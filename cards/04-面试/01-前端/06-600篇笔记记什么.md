# 600 多篇笔记都记什么

## 30 秒版

记的是开发中真实遇到的问题和解法，前端为主，也有后端和部署。不是收藏夹，也不是知识点摘抄，每篇都对应一次具体的坑。写了六百多篇，全部公开可查。

## 展开

- 为什么要公开：公开就有读者，有读者才不敢糊弄；也是防守年龄偏见最实在的一条证据
- 和「知识点文件夹」的区别：按问题组织，一篇一坑，能直接照着做
- 边界：不是系统教程，覆盖度不均，前端明显多于其他方向

## 我的数字

- docs 下约 630 篇，VuePress Theme Hope + Markdown
- 地址 <https://cqlql.github.io>，面试前先自己点开确认能访问

## 追问预演

- **Q**：都记些什么？
  **A**：开发里踩到的坑和解法。比如某个构建报错怎么绕、某个接口为什么这么设计、Docker 里字体缺失怎么补。一篇一坑。
- **Q**：为什么公开？
  **A**：公开才有压力写清楚。而且它是我持续在写这件事的证据，比简历上一句「热爱学习」有用。
