# 准确率、幻觉率、耗时怎么定义

> 关键词桩，不是成稿。合上卡，用这几根桩自己连成 5 句话。

- 准确率：关键事实点是否命中 + 有没有引入资料外的陈述
- 幻觉率：只统计「说了但资料里没有」的内容，边界要写死
- 耗时拆开记：检索 / rerank / 生成首 token / 生成总时长
- 只定三个是为了能归因，三个刚好对应三个优化方向

## 展开

**准确率**：不是「和参考答案字面一致」，而是「关键事实点全部命中 + 没有引入资料外的错误陈述」。三档判定：

- 完全正确：关键点全覆盖，无编造
- 部分正确：缺关键点，但没编（可以算半分或算错，**要提前定死**）
- 错误：编造了，或答非所问

**幻觉率**：分母是「所有回答」，分子是「包含至少一处编造的回答」。编造包括：编字段、编数字、把不存在的来源说成存在、把资料里 A 的属性安到 B 上。**必须写清边界**：

- 回答说「资料里没有提到」→ **不算**幻觉
- 资料说 A>B、B>C，回答 A>C → **不算**幻觉（合理推理）
- 只对检索到的 top-k 判定（不要求模型知道全库）

不写边界，两个人算出来的幻觉率能差一倍。

**耗时**：端到端（用户感知）+ 拆分（检索 ms / rerank ms / 生成首 token ms / 生成总时长）。RAG 场景 3~5 秒是心理阈值；首 token 决定「感觉快不快」；拆开是为了定位——检索 800ms + 生成 2s 时，优化方向完全不同（检索能加缓存/换 ANN，生成只能换小模型/流式）。

**为什么只定三个**：能归因。指标多了会互相矛盾（准确率涨但幻觉率也涨，看不出该改哪），而且没人看。三个刚好对应三个优化方向：

| 指标 | 变差时该改什么 |
|---|---|
| 准确率 | 检索质量、prompt |
| 幻觉率 | 约束（「资料里没有就说没有」）、引用机制 |
| 耗时 | 检索链路、模型选型、流式 |

每个指标都要配「谁判、怎么判、抽样多少」三件套，否则数字不可复现。

## 追问预演

- **Q**：准确率的判定标准是什么？谁判的？
  **A**：**要点**：标准要可操作（关键点 checklist + 是否引入资料外陈述），三档判定。「部分正确」怎么算要提前定死（算错还是半分），否则数字没法复现。谁判：人工标全量做基准，judge 跑后续版本，一致率 80%+ 才信 judge。

- **Q**：幻觉率怎么算才不是拍脑袋？边界怎么定？
  **A**：**要点**：三件套——定义（陈述在检索到的资料里找不到依据）、边界（排除「承认不知道」、排除合理推理）、流程（只对 top-k 判定，两人各判 20 条算一致率）。**关键是边界写下来**，否则换个人算就差一倍。

- **Q**：为什么只定三个指标？不多测几个吗？
  **A**：**要点**：能归因。三个分别对应三个优化方向（检索/prompt、约束/引用、链路/选型），互相矛盾时也知道该看哪个。多了会互相打架且没人看。如果追问「还要加什么」，答「上线后加业务指标：追问率、转人工率、用户满意度」。

- **Q**：耗时是端到端还是首 token？为什么要拆开记？
  **A**：**要点**：两个都要——端到端是用户感知（3~5 秒是阈值），首 token 是「感觉快不快」。拆开是为了**定位**：检索 800ms + 生成 2s，优化方向完全不同。只记总时长的话，改了半天不知道改对没有。
