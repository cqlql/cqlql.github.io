> 关键词桩，不是成稿。合上卡，用这几根桩自己连成 5 句话。

- 四类偏差：偏好长答案、偏好自己的输出、位置偏差、偏好格式漂亮的
- 一致率 = judge 与人工同批判定一致比例，低于 80% 说明 judge prompt 有问题
- judge 是放大器不是裁判：全量跑 judge，人工校准 judge
- 不一致样本是最值钱的东西，能看出 judge 错在哪

## 展开

**已知偏差与缓解**

| 偏差 | 表现 | 缓解 |
|---|---|---|
| 长度偏差 | 长答案得分高（信息量看起来大） | prompt 里明确「长度不是评分维度」；做长度对照实验验证 |
| 自我偏好 | 同模型当 judge 给自己的输出打高分 | 换不同家族的模型当 judge |
| 位置偏差 | A/B 对比时偏第一个 | 交换顺序各判一次，不一致就算平局 |
| 格式偏差 | markdown 排版漂亮的分高 | 评分维度拆开，格式单独一项、低权重 |

**judge prompt 怎么写**：给评分维度 + 每档的具体描述 + 反例（什么情况该给低分）+ 要求**先输出理由再给分**（CoT 能显著提升一致率）。维度越具体，一致率越高；「请评价这个回答好不好」这种 prompt 一致率必然低。

**一致率怎么算**：同一批 N 条样本，人工标一遍、judge 标一遍，`一致条数 / N`。分类任务更严谨用 Cohen's kappa（扣掉随机一致）。**低于 80% 基本说明 judge prompt 有系统性问题**，不是「模型不行」。

**定位**：judge 是放大器，不是裁判。全量数据用 judge 跑（100 条 × 每次改动都跑，成本可接受），人工只用来校准 judge（抽 20~30 条）。反过来（人工跑全量）成本不可持续；只跑 judge 不校准（judge 偏差不会被样本量抵消，1000 条一样偏）。

**不一致样本是最有价值的东西**：把 judge 和人工不一致的挑出来看，如果都是「长答案 judge 给高分」，那就是长度偏差；如果都是「格式漂亮但内容错」，那就是格式偏差。**发现偏差的方法不是读论文，是做一致率分析。**

## 追问预演

- **Q**：judge 会有什么系统性偏差？你怎么发现的？
  **A**：**要点**：列四类（长度 / 自我偏好 / 位置 / 格式），然后**重点说怎么发现的**——做一致率分析，把不一致样本挑出来归类。如果都是长答案分高，就是长度偏差。这一步不做，就只是「听说有偏差」。

- **Q**：一致率怎么算？算出来 65% 怎么办？
  **A**：**要点**：`一致条数 / 总条数`（更严谨用 kappa 扣随机）。65% 说明 judge prompt 有系统性问题：先看 10 条不一致样本找模式，然后改 prompt（补反例、拆维度、要求先给理由），改完重测。**不要直接信 judge 的分，也不要直接换成人工全标。**

- **Q**：为什么不能只用 judge，不加人工？
  **A**：**要点**：judge 的偏差是**系统性的**，不是随机噪声，所以不会因为样本多而抵消——1000 条一样偏。人工的作用不是「多标一些」，是「校准尺子」。另外 judge 判断不了「事实是否正确」（它不知道 ground truth），只能判断「看起来对不对」。

- **Q**：judge 用同一个模型还是换一个更强的？
  **A**：**要点**：换**不同家族**的更强模型最好，能避开自我偏好。折中：同尺寸但不同家族的模型（生成用 A，judge 用 B）。只能用同一个时，prompt 里加「严格评分」约束，并用人工一致率验证有效性。
