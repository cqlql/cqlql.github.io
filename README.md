## 命名约定

- 简历：`简历-<方向>.md`
- 面试准备：`面试准备-<方向>.md`
- 新增方向时成对添加，并在上表登记

## 各版本必须一致的内容

改一处就要全改，否则投出去的两份简历会打架：

- 姓名、年龄、电话、邮箱、期望薪资、期望城市
- 教育经历
- 早期工作经历（旅美美 2020.01-2022.06、深度教育 2014.12-2019.10、简乐 2012.07-2014.12）

## 导出

投递前导出 PDF，文件名用 `陈桥黎-<方向>.pdf`（如 `陈桥黎-前端开发.pdf`），不要用 `简历-前端开发.pdf` 这种不带姓名的。
