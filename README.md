# 大模型应用 · 学习训练场

> 不是笔记本，是训练场。笔记是副产品，能讲出来才是产物。

配套计划：[`cqlql-notes-resume/学习计划-RAG与Agent.md`](../cqlql-notes-resume/学习计划-RAG与Agent.md)
配套项目：[`notes-rag`](../notes-rag/README.md) —— 卡片里那些「我的数字」，全靠它跑出来

---

## 怎么用（三步）

**1. 双击 `dist/index.html`** —— 打开就是今天该复习的卡。

**2. 在心里答一遍，再点开看答案。**

**3. 给自己打分**

| 打分 | 含义 | 下次 |
|---|---|---|
| `1` | 没答上来 | 明天 |
| `2` | 说清了但没讲透取舍 | 3 天后 |
| `3` | 能扛住追问 | 7 天后（连对三次转 21 天） |

**打分要狠。** 含糊就给 2，别给 3 —— 自欺的代价是面试当场被问穿。

键盘也能操作：`空格` 翻面，`1` `2` `3` 打分。

## 写卡片

卡片是 `cards/` 下的 md 文件，一张卡只回答一个问题。新建就复制 `cards/_模板.md`，改名，写。

四段结构，缺一不可：

```markdown
## 30 秒版
面试官问「讲讲 X」，你脱口而出的版本。超过 5 句就是没想清楚。

## 展开
追问「为什么这么选」时用。放取舍、放对比、放你排除掉的方案。

## 我的数字
只有你有的东西：跑出来的 recall、耗时、成本，或踩过的具体坑。

## 追问预演
- **Q**：那为什么不直接用 XXX？
  **A**：...
```

⚠️ 这四个标题**不要改名**，页面靠它们取内容。

**没填的卡也能点开**，会显示「面试官会这么问」的四个问题——不知道怎么写的时候，照着问题答一遍就是答案。

### 三条铁律

1. **不许复制粘贴文档原文**。用自己的话说，说不清就是没懂。
2. **「我的数字」不许空**。没有数字就去跑一次，跑不了就写「还没做」，页面会标红提醒。
3. **一张卡只回答一个问题**。想写两个就拆两张。

## 改完卡片：双击 `rebuild.bat`

改完 md，双击 `rebuild.bat`，它会重新生成页面并自动打开。就这一步，不用记命令。

（等价命令：`node tools/build.mjs`）

## 目录

```
llm-learning/
├── dist/index.html    ← 双击这个复习（自动生成，别手改）
├── rebuild.bat        ← 改完卡片双击这个
├── cards/             ← 卡片在这里，一卡一问
│   ├── 01-rag/        （7 张）
│   ├── 02-agent/      （6 张）
│   └── 03-eval/       （3 张）
├── 进度.md            ← 每周日更新：本周任务、验收线、卡点
├── 实验台账.md         ← 数字资产：recall@5、chunk size 对比、耗时
├── 疑问.md            ← 想不通的扔这，解决后升级成卡片
└── 日志/2026-10.md    ← 每天 3 行，不写小作文
```

**卡片即清单**：填完就是学完，页面顶部 `1/16` 就是进度条，不用另外维护学习清单。

## 为什么不做「知识点文件夹」

建个 `知识点/` 目录把定义抄进去，那是收藏夹，不是学习。它必然走向：抄的时候觉得懂了 → 一周后像看别人的笔记 → 越攒越多越不敢打开 → 废弃。

**面试不考「你见过」，考「你能讲」。** 所以这里按**面试问题**组织，答案写成**能背的 30 秒口播版**，并且逼你合上资料说出来。

三个设计取舍：

- **答案留空**：只有第一张（`01-为什么需要RAG.md`）写满了当示范，其余 15 张只给问题。答案必须自己写，这是学习发生的地方。
- **「我的数字」单独一段**：面试区分度全在这。你说「用了 RAG」和「recall@5 从 0.62 提到 0.81」，是两个量级。
- **不做打卡表**：打卡只证明你坐了 2 小时，不证明学会了。用抽题代替。

---

## 每周日：20 分钟

1. 打开页面 → `全部卡片` → 筛「待填」，看还剩几张没写
2. 更新 `进度.md`：一句话写「这周我能讲什么了」
3. 对照学习计划的**验收线**打勾。不达标不进下一阶段

---

## 阶段结束后：往笔记站搬

卡片是给自己练的，写得糙没关系。**阶段验收通过后**，把想长期留的整理成干净笔记，放进 `cqlql-notes/docs/ai/`。

⚠️ 别把学习卡片直接塞进笔记站：`notes-rag` 要用笔记站当语料，学习卡片混进去会污染评估集（问自己的问题、检索自己的答案，recall 虚高）。

## 备用：终端版

不想开浏览器时（SSH、改完卡片想立刻自测）：

```bash
node tools/review.mjs --list     # 看进度
node tools/review.mjs            # 抽 3 张
node tools/review.mjs --help     # 全部参数
```

页面把记录存在浏览器 localStorage，终端版存在 `tools/review-state.json`，两边通过页面底部的**导出/导入**同步。
