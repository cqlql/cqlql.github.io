## 为什么不是「知识点文件夹」

建一个 `知识点/` 目录，把看到的定义抄进去，这是**收藏夹**，不是学习。它有三个必然结局：

1. 抄的时候觉得懂了，一周后打开像看别人的笔记
2. 没有任何东西逼你复述，所以永远停在「见过」
3. 越攒越多，越不敢打开，最后废弃

**面试不考「你见过」，考「你能讲」。** 所以这里的一切设计都指向一个动作：**合上资料，说出来**。

三处关键差异：

| 收藏夹式笔记 | 这里 |
|---|---|
| 按主题归类知识点 | 按**面试问题**组织，一卡一问 |
| 答案写给自己看 | 答案写成**能背的 30 秒口述版** |
| 写完即完成 | 写完只是开始，**要过抽题关** |
| 记「学到了什么」 | 记「**我的数字是多少**」——面试区分度在这 |

## 目录

```
llm-learning/
├── 进度.md          # 唯一看板：本周干什么、勾到哪、卡在哪
├── 实验台账.md       # 数字资产：recall@5、chunk size 对比、耗时。简历直接引用
├── 疑问.md          # 想不通的先扔这，解决后升级成卡片
├── cards/           # 核心：一卡一问，按阶段分目录
│   ├── 01-rag/      # 7 张
│   ├── 02-agent/    # 6 张
│   └── 03-eval/     # 3 张
├── 日志/2026-10.md  # 按月一个文件，每天 3 行，不写小作文
└── tools/review.mjs # 抽题脚本：按遗忘曲线挑今天该复习的卡
```

**卡片即清单**。不需要另外维护一份「学习清单」——卡片填完就是学完，`review.mjs --list` 就是进度条。

## 每天怎么用（15 分钟 + 2 小时动手）

### 早上 / 通勤：抽 3 张（3 分钟）

```bash
cd D:/_work/llm-learning
node tools/review.mjs
```

屏幕出问题 → 你先在心里答 → 回车看答案 → 给自己打分：

- `1` 没答上来 → 明天再来
- `2` 说清了但没讲透取舍 → 3 天后
- `3` 能扛住追问 → 7 天后，连续三次 3 分进 21 天

**打分要狠。** 答得含糊就给 2，别给 3——自欺的代价是面试当场被问穿。

### 白天：动手 2 小时

按 `进度.md` 的当周任务做，产出落到 `rag-lab` 或 PassUp 仓库。**遇到想不通的，立刻写进 `疑问.md`**，别停在原地想超过 10 分钟。

### 睡前：写 3 行（3 分钟）

打开 `日志/2026-10.md` 追加：

```markdown
## 10-31 周五
- 做了：跑通 bge-m3 向量化，500 篇笔记入库
- 数字：入库 487 块，平均 312 字/块
- 卡住：pgvector 的 HNSW 建索引比 IVFFlat 慢 4 倍，不知道为什么
```

**「数字」那一行最重要。** 它是 `实验台账.md` 的原料，也是面试时「你怎么知道有效」的答案。

## 卡片怎么写

新建卡片：复制 `cards/_模板.md`，改文件名（`序号-短标题.md`）。

四段结构，缺一不可：

```markdown
## 30 秒版
面试官问「讲讲 X」，你脱口而出的版本。超过 5 句就是没想清楚。

## 展开
追问「为什么这么选」时用。放取舍、放对比、放你排除掉的方案。

## 我的数字
只有你有的东西。跑出来的 recall、耗时、成本，或踩过的具体坑。
这一节空着 = 这张卡还没及格。

## 追问预演
- Q: 那为什么不直接用 XXX？
  A: ...
```

**写卡片的唯一标准：写完之后，合上文件能复述。** 写不出来说明还没懂，回去看代码，别抄文档。

### 三条铁律

1. **不许复制粘贴文档原文**。用自己的话说，说不清就是没懂。原文链接放文末「参考」即可。
2. **「我的数字」不许空**。没有数字就去跑一次，跑不了就写「还没做」并留在 `1` 分。
3. **一张卡只回答一个问题**。想写两个问题就拆两张。

---

## 每周日：20 分钟复盘

1. `node tools/review.mjs --list` 看多少卡还是 1 分——**1 分超过 30% 说明这周进度虚高**
2. 更新 `进度.md` 的本周结论：一句话写「这周我能讲什么了」
3. 对照学习计划的**验收线**打勾。不达标不进下一阶段——半懂不懂比不懂更容易被问穿

---

## 阶段结束：往笔记站搬

卡片是给自己练的，写得糙没关系。**阶段验收通过后**，把真正想长期留的整理成一篇干净笔记，放进
`cqlql-notes/docs/ai/`，那边有搜索、有导航、能对外。

⚠️ 别把学习卡片直接塞进笔记站：`rag-lab` 要用笔记站当语料，学习卡片混进去会污染评估集（问自己的问题、检索自己的答案，recall 虚高）。两边分开。
