# 毛玻璃

## backdrop-filter：模糊「背后」的内容

元素自身内容保持清晰，只模糊它下层的背景，常用于弹层、导航栏。

```css
background-image: radial-gradient(transparent 1px, #fff 1px);
background-size: 4px 4px;
backdrop-filter: saturate(50%) blur(4px);
```

## filter：模糊「元素自身」

让元素连同内容一起变模糊。

```css
filter: blur(3px);
-webkit-filter: blur(3px); /* 旧版 Safari / Chrome 前缀 */
```

> 区别：`backdrop-filter` 作用于元素背后的区域，`filter` 作用于元素本身。
