# 代码拆分与异步加载

只有真正执行到时才加载对应模块，是按需加载与减小首包体积的核心手段。

## 动态 import（推荐）

```js
function determineDate() {
  import('katex')
    .then((katex) => console.log(katex))
    .catch((err) => console.log('Failed to load katex', err))
}
// 仅声明不会下载；执行后才下载，实现按需
```

> 旧方案需 `babel-plugin-syntax-dynamic-import`，新版 `@babel/preset-env` 已原生支持动态 `import()`。

### 魔法注释：自定义包名

需设置 `output.chunkFilename` 配合：

```js
module.exports = {
  output: { chunkFilename: 'js/[name].bundle.js' },
}

const getComponent = async () => {
  const _ = await import(/* webpackChunkName: "lodash" */ 'lodash')
  return _.join(['Hello', 'webpack'], ' ')
}
```

### 魔法注释：合并异步模块

相同注释包名会被打成一个异步包，最大化减少请求数：

```js
const Foo = () => import(/* webpackChunkName: "group-foo" */ './Foo.vue')
const Bar = () => import(/* webpackChunkName: "group-foo" */ './Bar.vue')
const Baz = () => import(/* webpackChunkName: "group-foo" */ './Baz.vue')
```

## 异步模块的重复规则（核心总结）

- **公共包永不重复**：抽离出来的公共包，在异步模块中同步或异步调用都不会重复。
- **固定异步调用某模块安全**：多个位置异步调用非公共模块 C，C 会被单独打包成公共异步模块，不重复。
- **异步中同步调用非公共模块会重复**：某异步模块同步调用模块 C（非公共），C 会包含进该异步包；别的异步模块也调用 C 时会各自重复包含。
- **异步中异步调用某模块安全**：多个异步模块异步调用同一模块 D，D 单独打包成异步模块，不重复。

> 建议统一以异步形式调用共享模块，避免同步引用带来的重复打包。

## require.context 批量导入

批量导入目录下匹配的模块，避免逐个 `import`：

```js
// directory, useSubdirectories, regExp
const routes = []
function importAll(r) {
  r.keys().forEach((key) => {
    routes.push(r(key).default)
  })
}
importAll(require.context('./', false, /\/(?!index).+\.js$/))
```

- 正则由 webpack 在构建期解析，**不能**用 `new RegExp(str)` 或变量动态拼路径。
- 同样支持环境变量控制是否编译：

```js
if (process.env.NODE_ENV === 'production') {
  importAll(require.context('./router', false, /(use-car|commonPage)\.js$/))
} else {
  routes = require('./nav-dev.js').default
}
```

## 异步 CSS 模块

异步导入 CSS（如 `import('./base.css')`）报错缺少 `style-loader/lib/addStyles.js` 时，可在入口补一句：

```js
import(/* webpackChunkName: "katexcss" */ 'style-loader/lib/addStyles.js')
```
