# 开发服务器 devServer

基于 `webpack-dev-server` 提供本地热更新与接口代理。

## 基础配置

```js
module.exports = {
  devServer: {
    static: './dist',
    port: 9000,
    open: true,
    hot: true, // 开启热模块替换 HMR
  },
}
```

> 访问页面需带文件名，例如生成 `demo.html` 则地址为 `http://localhost:9000/demo.html`（404 Cannot GET / 通常是没指定访问页）。

## 接口代理

开发期无需本机部署后端，用代理转发接口：

```js
module.exports = {
  devServer: {
    proxy: {
      '/note': {
        target: 'http://192.168.1.222:8800',
        // 转发后去掉前缀：/note/xxx -> http://192.168.1.222:8800/xxx
        pathRewrite: { '^/note': '' },
        // 部分服务器需要手动设置 Host 头
        onProxyReq(proxyReq) {
          proxyReq.setHeader('Host', 'parent.shendupeiban.com')
        },
      },
    },
  },
}
```

## HMR 手动接入（自定义中间件方案）

使用 `webpack-dev-middleware` + `webpack-hot-middleware` 自行搭建时，每个 entry 需引入热更新客户端：

```js
entry: {
  page1: ['webpack-hot-middleware/client?reload=true', './src/page1.js'],
}
```

`reload=true` 表示热替换失败则强制刷新浏览器。各模块还需声明接受热更新：

```js
if (module.hot) {
  module.hot.accept()
}
```

HTML 变更刷新需借助 `eventsource-polyfill`：

```js
require('eventsource-polyfill')
const hotClient = require('webpack-hot-middleware/client?noInfo=true&reload=true')
hotClient.subscribe((event) => {
  if (event.action === 'reload') window.location.reload()
})
```

服务端推送刷新（结合 html-webpack-plugin 的编译后事件）：

```js
compiler.hooks.compilation.tap('reload', (compilation) => {
  compilation.hooks.htmlWebpackPluginAfterEmit.tap('reload', (data, cb) => {
    hotMiddleware.publish({ action: 'reload' })
    cb()
  })
})
```

> 现代项目直接用 `devServer.hot` 即可，上面的自定义方案仅在需要完全掌控 Node 服务时才有必要。

## Node API 启动

webpack.config.js 需放在根目录：

```js
require('webpack-dev-server/bin/webpack-dev-server')
```
