# 常用插件

## DefinePlugin（注入环境变量）

```js
const webpack = require('webpack')

module.exports = {
  plugins: [
    new webpack.DefinePlugin({
      'process.env': {
        NODE_ENV: JSON.stringify('production'),
        WEB_TEST: JSON.stringify('false'),
      },
    }),
  ],
}
```

- 代码中 `if (process.env.NODE_ENV !== 'production') {...}` 在 production 下整块被删除，不进产物。
- 三元运算符 `true ? 1 : 0` 压缩后为 `1`，多余代码同样被消除。
- 支持 `require` / `require.context`，但只能用 CommonJS 语法。
- **未声明的变量不会变成 `false`**，相关代码块压缩后不会被删除。
- 多个 `DefinePlugin` 同名变量以第一次为准，不同名互不影响。

## html-webpack-plugin

生成 HTML 并自动注入打包后的资源。

```js
const HtmlWebpackPlugin = require('html-webpack-plugin')

module.exports = {
  plugins: [
    new HtmlWebpackPlugin({
      filename: './index.html',
      template: './src/index.html',
      chunks: ['manifest', 'common', 'app'],
      minify: {
        removeComments: true,
        collapseWhitespace: true,
        removeAttributeQuotes: true,
        minifyCSS: true,
      },
    }),
  ],
}
```

- 模板默认使用 EJS 语法。
- 多 chunk 顺序错乱时，用 `chunksSortMode` 自定义排序函数控制。
- 排除指定 chunk 可用 `excludeChunks`（自带的），或配合 `html-webpack-exclude-assets-plugin`。

## MiniCssExtractPlugin

将 CSS 抽离为独立文件（见 [02-Webpack4到5](./02-Webpack4到5.md)）。

## 缓存：NamedModulesPlugin / HashedModuleIdsPlugin

避免文件内容未变但构建 id 变化导致缓存失效：

```js
module.exports = {
  output: {
    filename: 'js/[name].[chunkhash:4].js',
    chunkFilename: 'js/[name].bundle.[chunkhash:4].js',
  },
  plugins: [
    new webpack.HashedModuleIdsPlugin(), // 推荐：id 换成路径 hash
    // new webpack.NamedModulesPlugin(), // 用路径名标识（开发期可读性更好）
  ],
}
```

> 注意使用 `[chunkhash]` 而非 `[hash]`；`[hash]` 任意文件变动都会让所有文件 hash 改变。

## externals：引入不编译的库

适合用 CDN 引入或跨项目共享的全局库：

```js
module.exports = {
  externals: {
    vue: 'Vue', // 左边模块名，右边全局变量
  },
}
```

配合拷贝与注入资源（非 CDN 场景）：

```js
const CopyWebpackPlugin = require('copy-webpack-plugin')
const HtmlWebpackIncludeAssetsPlugin = require('html-webpack-include-assets-plugin')

plugins: [
  new CopyWebpackPlugin({ patterns: [{ from: 'node_modules/vue/dist/vue.min.js', to: './vue.min.js' }] }),
  new HtmlWebpackIncludeAssetsPlugin({
    files: ['./single_v2.html'],
    assets: ['vue.min.js'],
    append: false,
  }),
]
```

## DllPlugin & DllReferencePlugin

把不常变动的第三方库预打包成 DLL，加速二次构建。注意：官方动态 `import()` 与之配合不佳，强用会产生多余的中间动态文件。
