## 抛出异常 throw

手动让程序报错，程序将终止后续代码执行。

```js
throw "Error2"; // 抛出字符串异常
throw 42;       // 抛出数字异常
throw true;     // 抛出布尔异常
throw new Error('出错了');
```

## 捕获异常 try...catch

阻止程序因异常而终止运行。

```js
// 捕获自定义异常
try {
  throw '错误1'
} catch (e) {
  console.log(e) // '错误1'
}

// 捕获程序异常（抛出的是 Error 对象）
try {
  a // 未定义
} catch (e) {
  console.log(e) // Error 对象
}
```

### try 能否捕获函数中的错误

方法内部抛错，只要在调用处（入口）用 try 包裹，就能捕获。因此在顶层入口统一 try...catch 即可避免程序整体中断。

```js
function test() {
  testChild()
}
function testChild() {
  throw new Error('err')
}

try {
  test()
} catch (err) {
  console.log(err)
}
```

### finally

无论是否抛错都会执行，常用于释放资源。

```js
try {
  // ...
} catch (e) {
  // ...
} finally {
  // 始终执行
}
```

## Error 对象

`new Error('test')` 能提供堆栈信息（`stack`）、消息（`message`）、名称（`name`）。

```js
console.dir(new Error('test'))
```

内置错误子类：

| 子类 | 触发场景 |
| --- | --- |
| `EvalError` | 在 `eval()` 中执行代码出错 |
| `RangeError` | 数值/参数超出有效范围 |
| `ReferenceError` | 引用了无效的引用（如未声明变量） |
| `SyntaxError` | 解析代码时语法错误 |
| `TypeError` | 变量或参数类型不合法 |
| `URIError` | `encodeURI()` / `decodeURI()` 传入无效参数 |
