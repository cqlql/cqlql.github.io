零散但实用的类型编程技巧。

## 直接拿实例的类型

```ts
const createI18n = {}
type I18n = ReturnType<typeof createI18n>
```

## 类型函数的实现原理（推导返回值）

```ts
/**
 * Obtain the return type of a function type
 */
type ReturnType<T extends (...args: any) => any> = T extends (...args: any) => infer R ? R : any
```

`infer` 用于在条件类型中"占位"推导某个位置的类型。

## 类型的所有 key 作为类型（去只读）

```ts
export type Writable<T> = {
  -readonly [P in keyof T]: T[P]
}
```

## 心得

先写类型约束，再用 `?` / `infer` 逐步收窄，比事后断言更稳。

## 第三方模块类型扩展注意事项

最外层 `import type` 其他类型可能导致后续 `declare module` 失效。可在 `module` 内部 `import` 或用 `import()` 方式解决：

```ts
// 最外层引入其他类型会导致后定义的模块失效，故改为：
declare module 'sortablejs/modular/sortable.core.esm' {
  import type { OnSpillPlugin } from '@types/sortablejs/plugins'
  export const OnSpill: OnSpillPlugin = {}
  // 或
  export const OnSpill2: typeof import('@types/sortablejs')['OnSpill'] = {}
}
```
