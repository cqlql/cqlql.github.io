TypeScript 内置的工具类型速查。

## Exclude<T, U>

从 `T` 中排除可赋值给 `U` 的部分。

```ts
type Exclude<T, U> = T extends U ? never : T;

type Name = string | null | undefined
let name: Exclude<Name, null | undefined> // string

// 安全排除：约束 U 必须是 T 的子类型
type SafeExclude<T, U extends T> = Exclude<T, U>
type ValueMode = 'none' | 'custom' | 'formula' | 'binding'
const v: SafeExclude<ValueMode, 'custom' | 'none'> = 'binding'
// const v2: SafeExclude<ValueMode, 'custom2'> = 'binding' // error
```

## Extract<T, U>

从 `T` 中提取可赋值给 `U` 的部分。

```ts
type Extract<T, U> = T extends U ? T : never;

interface IPerson { name: string; age: number; sex: 0 | 1 }
interface IMan { name: string; age: number }
type Man = Extract<IPerson, IMan> // 等效 IPerson

type Fruits = 'apple' | 'banana' | 'peach' | 'orange'
type Dislike = 'apple' | 'banana'
type Love = Extract<Fruits, Dislike> // 'apple' | 'banana'
```

## Pick<T, K>

从 `T` 中挑选一组属性，原样复制（保持可选/必选）。

```ts
type User = { name?: string; age?: number }
type UserPicked = Pick<User, keyof User>
const user: UserPicked = {}
```

## Partial / Required / Readonly

- `Partial<T>`：所有属性变为可选。
- `Required<T>`：所有属性变为必选。
- `Readonly<T>`：所有属性变为只读。

```ts
type User = { name: string; age: number }
type UserPartial = Partial<User>

interface Person {
  readonly id: number
  name: string
  age?: number
}
```

## 覆写类型

### 单个覆写 —— Omit

本质是排除某个成员后重新定义。

```ts
interface A { a: number; b: number }
interface B extends Omit<A, 'a'> { a: boolean }
```

### 批量覆写 —— Merge

```ts
type Merge<M, N> = Omit<M, Extract<keyof M, keyof N>> & N

// 示例
interface A { name: string; color?: string }
type B = Merge<A, { name: string | number; favorite?: boolean }>
```

## 其他实用技巧

字段必须有、值可空（对接数据时防漏字段）：

```ts
type RequiredKey<T> = { [K in keyof Required<T>]: T[K] }
type Original = { name?: string; age?: number; active?: boolean }
const example: RequiredKey<Original> = { name: undefined, age: undefined, active: undefined }
```
