## 扩展现有模块类型


```typescript
import 'codemirror';
declare module 'codemirror' {
  interface Editor {
    // CodeMirror.Editor 下并没有 display，所以通过这种方式扩展    
    display: {
      lineDiv: HTMLDivElement;
    };
  }
}
```



参考文档：[Typescript声明文件-第三方类型扩展](https://segmentfault.com/a/1190000022842783)



## 扩展window
```typescript
// 1
interface Window {
  myFunction(data: any): void;
}

// 2
declare global {
  interface Window {
    myFunction(data: any): void
  }
}
```

## 定义全局变量
注意，是全局变量，非类型（因为类型不能用作变量，只能用作声明）。扩展的window也不是全局的，一定要通过window才能使用。这种方式直接就能使用

```javascript
// 不加 typeof 就是一个实例
declare const ClassicEditor: (typeof import('@ckeditor/ckeditor5-editor-classic'))['ClassicEditor']

```
