TypeScript 是 JavaScript 的类型化超集，编译后产出纯 JS。本文为速查入口，列出各主题与要点。

## 术语

- **索引签名 (Index Signature)**：`[key: string]: number` 形式的键类型声明。
- **调用签名 (Call Signature)**：描述"可像函数一样被调用"的类型，如 `(source: string) => boolean`。
- **构造器签名 (Construct Signature)**：`new (...args) => T`。

## 基础类型速览

| 名称 | 类型 | 例子 |
| --- | --- | --- |
| 布尔值 | `boolean` | `let isDone: boolean = false` |
| 数字 | `number` | `let dec: number = 6` |
| 字符串 | `string` | `let name: string = 'bob'` |
| 数组 | `T[]` / `Array<T>` | `number[]`、`Array<number>` |
| 元组 | `[T, U]` | `let x: [string, number]` |
| 枚举 | `enum` | `enum Color { Red, Green }` |
| Any | `any` | `let notSure: any = 4` |
| Void | `void` | 只能赋 `undefined` / `null` |
| Null/Undefined | `null` / `undefined` | — |
| Never | `never` | 永不存在的值 |
| Object | `object` | `let obj: object = { prop: 0 }` |

详细见 [02_基础类型](./02_基础类型.md)。
