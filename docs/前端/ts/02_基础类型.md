## 数组

```ts
let list: number[] = [1, 2, 3]          // 方式 1
let list: Array<number> = [1, 2, 3]     // 方式 2
let list: string[] = ['bar', 'foo']

// 多维
let arr1: number[][] = [[1, 11], [2, 22]]
let arr2: Array<Array<number>> = [[1, 11], [2, 22]]
```

## 元组 Tuple

多种类型，顺序必须匹配。

```ts
let x: [string, number]
x = ['hello', 10] // OK
x = [10, 'hello'] // Error
```

## 枚举

```ts
// 默认数字，0 起始，可显式赋值
enum Direction {
  Up = 1,
  Down,
  Left,
  Right,
}
// 异构枚举
enum BooleanLikeHeterogeneousEnum {
  No = 0,
  Yes = 'YES',
}

// 用作类型
function respond(recipient: string, message: Direction): void {}
respond('Caroline', Direction.Up)

console.log(Direction.Down) // 2
```

## any / unknown / never / void

- `any`：完全放弃类型检查，尽量用 `unknown` 替代。
- `unknown`：未知类型，使用前需类型收窄。
- `never`：永不存在的值（如总是抛错的函数返回值）。
- `void`：函数无返回值。
