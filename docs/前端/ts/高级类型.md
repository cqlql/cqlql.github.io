## Exclude<T, U>
如果 U不包含 T，返回T，否则 never

```typescript
/**
 * Exclude from T those types that are assignable to U
 */
type Exclude<T, U> = T extends U ? never : T;
```



例子1：排除 null和undefined

```typescript
type Name = string | null | undefined
let name: Exclude<Name, null | undefined>
```



**扩展：**安全排除，确保 `T` 是 `U` 的子类型

```typescript
type SafeExclude<T,U extends T> = Exclude<T, U>;
// 使用
export type ValueMode = 'none' | 'custom' | 'formula' | 'binding';
const value:SafeExclude<ValueMode,'custom' | 'none'>='binding'
const value:SafeExclude<ValueMode,'custom2'>='binding'//error
```

## Extract<T, U>
如果 U包含 T，返回T，否则 never

```typescript
/**
 * Extract from T those types that are assignable to U
 */
type Extract<T, U> = T extends U ? T : never;
```



对象类型

```typescript
interface IPerson {
  name: string,
  age: number,
  sex: 0 | 1,
}

interface IMan {
  name: string,
  age: number,
}

type Man = Extract<IPerson, IMan> // 等效于 type Man = IPerson
```

联合类型

```typescript
type Fruits = "apple" | "banana"  | 'peach' | 'orange';
type DislikeFruits = "apple" | "banana";
type FloveFruits = Extract<Fruits, DislikeFruits> // 等效于 type FloveFruits = "apple" | "banana"
```

## Pick 选择复制
实现类型复制，原样复制，可为空也将保留，并且复制后的类型与原类型重构关联(重命名原类型，复制后的类型也会改变)。

```typescript
type User = {
  name?: string;
  age?: number;
};
type UserPickedNonNullable = Pick<User, keyof User>;
const user: UserPickedNonNullable = {};

console.log('🚀 -- user:', user.age);
```

## Partial 可选
修改为可选，与 Required 相反

```typescript
type User = {
  name: string;
  age: number;
};
type UserPickedNonNullable = Partial<Pick<User, keyof User>>;
const user: UserPickedNonNullable = {};

console.log('🚀 -- user:', user.age);
```
