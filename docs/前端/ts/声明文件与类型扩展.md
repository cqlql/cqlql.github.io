## 声明全局变量

```ts
// 1、直接 declare
declare let process: any

// 2、或包在 declare global 中
declare global {
  let process: any
}
```

由 `typeRoots` 指定的目录都会被视为全局类型：

```json
{
  "compilerOptions": {
    "typeRoots": ["./src/types", "./node_modules/vue/types"]
  }
}
```

## 给第三方对象/函数写声明文件

```ts
interface FileOptions {
  accept: string
  capture: string
  sizeLimit: number
}
interface FileSelect {
  file(options: FileOptions): Promise<any>
}
declare const fileSelect: FileSelect
export default fileSelect
```

```ts
interface DragOptions {
  elem: HTMLElement
  onDown(e: TouchEvent | MouseEvent): void
  onMove(e: TouchEvent | MouseEvent): void
}
declare function drag(options: DragOptions): void
export default drag
```

## 给 Vue 插件写声明文件

需与 `plugin.js` 同级同名（`plugin.d.ts`）：

```ts
import Vue, { PluginFunction } from 'vue'
declare const LoadingPlugin: PluginFunction<Vue>
export default LoadingPlugin
```

## 扩展 window

```ts
// 1. 直接声明（需放在全局 .d.ts）
interface Window {
  myFunction(data: any): void
}
// 2. 在 ts 文件中用 declare global
declare global {
  interface Window {
    myFunction(data: any): void
  }
}
// 动态属性
declare global {
  interface Window {
    [key: string]: any
  }
}
window['global_prop'] = 'hello'
```

## 扩展 NodeJS

```ts
declare namespace NodeJS {
  interface Process {
    env: {
      NODE_ENV: 'production' | 'development'
    }
  }
}
```

## 扩展现有模块类型

```ts
import 'codemirror'
declare module 'codemirror' {
  interface Editor {
    display: { lineDiv: HTMLDivElement }
  }
}
```

## 扩展 Uni（示例）

```ts
interface Uni {
  $u: { toast: (message: string) => void }
}
```

## 定义全局变量（非类型）

类型不能当变量用，定义全局变量用 `declare const`：

```js
// 不加 typeof 就是一个实例
declare const ClassicEditor: (typeof import('@ckeditor/ckeditor5-editor-classic'))['ClassicEditor']
```

## 引入类型模块

模块已安装却找不到，可能不在 TypeScript 默认搜索范围，可手动引入：

```ts
/// <reference types="vue-i18n" />
```

## 将类型导出为全局

```ts
export * from '@uni-helper/uni-app-types'
export * from '@uni-helper/uni-ui-types'
```

> 注意：在 `tsconfig.json` 的 `compilerOptions.types` 中配置上述包是**无效的**（见下方错误示例）：

```json
{ "compilerOptions": { "types": ["@uni-helper/uni-app-types"] } } // 错误：不会自动导出
```
