## 字段必须有，值保持不变
对接数据时，避免字段漏掉很有用

```typescript
type RequiredKey<T> = {
  [K in keyof Required<T>]: T[K];
};

type Original = {
  name?: string;
  age?: number;
  active?: boolean;
};

type ConditionalModified = RequiredKey<Original>

const example: ConditionalModified = {
  name: undefined, 
  age: undefined,
  active: undefined,
};
```
