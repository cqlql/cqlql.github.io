## interface 快速使用

1. **对象类型**：定义对象结构
2. **函数类型**（调用签名）
3. **可索引类型**：键值对，包括数组
4. **类类型**：配合 `implements`
5. 接口可继承接口，也可继承类

```ts
/** 1 对象类型 */
interface SquareConfig {
  color?: string              // ? 可选，不等于 `color: string | undefined`
  readonly x: number          // 只读
  cb(source: string, subString: string): boolean // 函数类型
}
function createSquare(config: SquareConfig): { color: string; area: number } {
  return { color: 'red', area: 1 }
}
createSquare({ color: 'red', x: 2, cb: () => true })

/** 2 函数类型 */
interface SearchFunc {
  (source: string, subString: string): boolean
}
let mySearch: SearchFunc = (s, sub) => s.search(sub) > -1

/** 3 可索引类型 */
interface StringArray {
  [index: number]: string
}
let myArray: StringArray = ['Bob', 'Fred']

/** 4 类类型 */
interface ClockInterface {
  currentTime: Date
}
class Clock implements ClockInterface {
  currentTime: Date
  constructor(h: number, m: number) {}
}
```

### 任意额外属性

```ts
interface SquareConfig {
  color?: string
  width?: number
  [propName: string]: any
}
```

### 构造器签名

```ts
interface ClockConstructor {
  new (hour: number, minute: number): ClockInterface
}
```

## type 类型别名

给类型自定义名字，甚至联合类型。

```ts
type Name = string
type NameResolver = () => string
type NameOrResolver = Name | NameResolver
```

## interface vs. type

**基本相同，能用 `interface` 就用 `interface`**（interface 可被声明合并、实现类，性能与报错更友好）。

**区别**：`type` 可以声明基本类型、联合类型、元组、函数类型等，而 `interface` 不行。

```ts
// type 能做的
type onmousewheel = ((this: GlobalEventHandlers, ev: WheelEvent) => any) | null

// interface 与 type 写法对比
export type SwipeOptions = {
  elem: HTMLElement
  onDown?(e: TouchEvent | MouseEvent): void
}
export interface SwipeOptions {
  elem: HTMLElement
  onDown?(e: TouchEvent | MouseEvent): void
}
```
