# [MediaDevices: getDisplayMedia()](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)

## getDisplayMedia 的行为

```
navigator.mediaDevices.getDisplayMedia({
  video: true,   // 捕获画面（默认true）
  audio: true    // 捕获音频（系统/应用音频）(默认false)
})
```

- 浏览器会弹窗让用户选择 **共享对象**：
  - **整个屏幕**（所有内容）
  - **某个应用窗口**（独立窗口）
  - **浏览器标签页**（当前或其他标签页）
- 如果用户选择 **浏览器标签页**：
  - 就可以捕获该标签页的 **视频+音频**。
  - 只限用户选择的标签页，网页无法后台偷偷捕获其他标签。

## 基本示例

```javascript
async function captureScreenAudio() {
  try {
    const stream = await navigator.mediaDevices.getDisplayMedia({
      video: true,       // 是否捕获屏幕画面
      audio: true        // ⚡ 捕获系统音频
    });

    // 查看音频轨道
    const audioTracks = stream.getAudioTracks();
    console.log('捕获到音频轨道:', audioTracks);

    // 可以播放声音（调试用）
    const audioEl = document.createElement('audio');
    audioEl.srcObject = stream;
    audioEl.autoplay = true;
    audioEl.controls = true;
    document.body.appendChild(audioEl);

    // 如果想分析音量
    const audioContext = new AudioContext();
    const source = audioContext.createMediaStreamSource(stream);
    const analyser = audioContext.createAnalyser();
    source.connect(analyser);

    // 示例：获取音量大小
    const dataArray = new Uint8Array(analyser.fftSize);
    function updateVolume() {
      analyser.getByteTimeDomainData(dataArray);
      let sum = 0;
      for (let i = 0; i < dataArray.length; i++) {
        let v = dataArray[i] - 128;
        sum += v * v;
      }
      let rms = Math.sqrt(sum / dataArray.length);
      console.log('音量大小:', rms);
      requestAnimationFrame(updateVolume);
    }
    updateVolume();

  } catch (err) {
    console.error('捕获屏幕音频失败:', err);
  }
}

captureScreenAudio();
```

## 去掉视频

```js
async function captureTabAudio() {
  try {
    const stream = await navigator.mediaDevices.getDisplayMedia({
      video: true,  // ⚠️ 必须为 true
      audio: true
    });

    // 如果你不需要视频，可以隐藏或丢弃
    const audioStream = new MediaStream(stream.getAudioTracks());
    console.log('捕获到音频流:', audioStream);

    // 可播放音频
    const audio = document.createElement('audio');
    audio.srcObject = audioStream;
    audio.autoplay = true;
  } catch (err) {
    console.error('捕获失败:', err.name, err.message);
  }
}

captureTabAudio();
```

### 为什么必须`video: true`：

在 **Edge（基于 Chromium）** 和 **Chrome** 中：

- `navigator.mediaDevices.getDisplayMedia({ video: false, audio: true })`
   → **报错 `NotSupportedError`**
- `navigator.mediaDevices.getDisplayMedia({ video: true, audio: true })`
   → **正常返回**

原因：

1. **标签页/窗口音频是依附于视频轨道的**
   - 浏览器捕获的音频轨道属于“屏幕捕获流”的一部分
   - 如果没有视频轨道，浏览器就无法关联音频轨道，所以报 `NotSupportedError`
2. **浏览器设计限制**
   - Chromium/Edge 规定：**只能在捕获视频的情况下捕获系统/标签页音频**
   - 所以即使你只想要声音，也必须 **至少有一个视频轨道**（哪怕是黑屏）
