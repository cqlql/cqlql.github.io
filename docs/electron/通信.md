
为了安全，现在浏览器中不能直接调用 electron nodejs api，electron 主线程也没法调用浏览器api，所以需要通信。

主要使用的模块 ipcMain ipcRenderer contextBridge 。


更多内容见[官方文档](https://www.electronjs.org/zh/docs/latest/tutorial/ipc)。



## 例子：监听主进程消息，使用 ElMessage 显示

### 一、整体结构（你先对齐这个）

```
Main
  └─ win.webContents.send('notify', payload)
Preload
  └─ ipcRenderer.on → 暴露监听 API
Renderer (Vue)
  └─ 调 ElMessage 显示
```

------

### 二、主进程：发送通知消息

```
// main.js
function notifyRenderer(win, options) {
  win.webContents.send('notify', {
    type: 'success', // success | warning | info | error
    message: '操作成功',
    duration: 3000
  });
}

// 使用示例
notifyRenderer(mainWindow, {
  type: 'success',
  message: '登录成功'
});
```

------

### 三、preload.js：安全桥（关键）

> ⚠️ **不要直接在 renderer 里用 ipcRenderer**

```js
// preload.js
const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('electronAPI', {
  onNotify: (callback) => {
    function listener(_, data) {
      callback(data);
    }
    ipcRenderer.on('notify', listener);

    return () => {
      ipcRenderer.removeListener('notify', listener);
    };
  }
});
```

### 四、渲染进程：监听并用 ElMessage 显示

#### 1️⃣ Vue 入口文件（推荐放这里，全局一次）

```
// main.ts
import { createApp } from 'vue';
import App from './App.vue';
import ElementPlus, { ElMessage } from 'element-plus';

const app = createApp(App);
app.use(ElementPlus);
app.mount('#app');

// 监听主进程通知
window.electronAPI.onNotify((options) => {
  ElMessage({
    type: options.type ?? 'info',
    message: options.message,
    duration: options.duration ?? 3000
  });
});
```

这样做的好处是：

- ✅ 只注册一次
- ✅ 全局生效
- ✅ 不跟组件生命周期纠缠

------

#### 2️⃣ 如果你更想放在某个 Vue 组件里

```
// App.vue / 任意组件
import { ElMessage } from 'element-plus';

let offNotify: (() => void) | null = null;

onMounted(() => {
  offNotify = window.electronAPI.onNotify((options) => {
    ElMessage(options);
  });
});

onBeforeUnmount(() => {
  offNotify?.();
});
```

⚠️ **注意**：
 如果组件会反复挂载，要记得 `removeListener`（否则会弹多次）

### 五、TypeScript 类型补全（强烈推荐）

#### 1️⃣ 定义类型

```
// types/electron.d.ts
export interface NotifyOptions {
  type?: 'success' | 'warning' | 'info' | 'error';
  message: string;
  duration?: number;
}

declare global {
  interface Window {
    electronAPI: {
      onNotify: (cb: (options: NotifyOptions) => void) => void;
    };
  }
}
```
