# 进程管理

> 进程查看、结束，以及通过 PID 追踪进程来源（启动命令、路径、是否系统服务等）。

## 查看进程信息

**按 PID 查看详细信息**
```bash
ps -ef | grep 3660
ps -fp 3660
```

**查看端口占用的进程**
```bash
lsof -i :8004
# 或
netstat -tulpn | grep 8004
```

**查看监听端口**
```bash
# 查看 nginx 监听端口
sudo ss -tlnp | grep nginx

# 查看 8000-8009 范围内的监听端口
sudo ss -tulnp | grep -E ':(800[0-9])\s'
```

## 结束进程

```bash
kill 3660
```

## 追踪进程来源（以 PID 3660 为例）

逐条执行下列命令，定位进程是谁、从哪里启动的：

1. **查看完整启动命令**
   ```bash
   ps -fp 3660
   cat /proc/3660/cmdline | tr '\0' ' '
   ```

2. **查看程序所在路径**
   ```bash
   ls -l /proc/3660/exe
   ```

3. **查看是否属于 systemd 托管服务**
   ```bash
   systemctl status 3660
   ```
   - 显示 unit 名称 → 是后台服务，可找到对应的 service 文件。
   - 提示无对应服务 → 手工在命令行启动，未注册成系统服务。

4. **查看父进程，确认在哪里拉起**
   ```bash
   ps -ef | grep 3660
   ```

5. **检查是否写进开机自启**
   ```bash
   # 定时任务
   crontab -l -u xdt
   # 开机启动脚本
   ls /etc/rc.local /etc/init.d/
   # 所有自定义服务
   ls /etc/systemd/system/*.service
   ```
