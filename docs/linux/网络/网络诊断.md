# 网络诊断

> IP / 网卡、网关、DNS 查看，以及文件下载示例。

## 查看 IP / 网卡

```bash
hostname -I
# 或
ifconfig        # 需安装 net-tools
# 或（以下等价）
ip addr         # = ip address = ip addr show = ip address show
```

## 查看网关、DNS

```bash
# 网关
ip route | grep default
# DNS
cat /etc/resolv.conf
```

## 下载文件（示例）

```bash
curl -O https://download.oracle.com/java/21/latest/jdk-21_windows-x64_bin.zip
```
