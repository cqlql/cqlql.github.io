# Ubuntu 24.04 代理配置指南

## 一、终端命令行代理（curl/wget/npm/git 等命令工具）

**写成 alias（推荐长期用）**

把下面加到 `~/.bashrc` 或 `~/.zshrc`：
```bash
# proxy aliases
alias proxyon='export http_proxy=http://192.168.1.221:7897 https_proxy=http://192.168.1.221:7897 all_proxy=socks5://192.168.1.221:7897 HTTP_PROXY=http://192.168.1.221:7897 HTTPS_PROXY=http://192.168.1.221:7897 ALL_PROXY=socks5://192.168.1.221:7897 no_proxy="localhost,127.0.0.1,::1,192.168.1.0/16,172.16.0.0/12,10.0.0.0/8,.cluster.local,.svc" NO_PROXY="localhost,127.0.0.1,::1,192.168.0.0/16,172.16.0.0/12,10.0.0.0/8,.cluster.local,.svc"'
alias proxyoff='unset http_proxy https_proxy all_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY no_proxy NO_PROXY'
```

生效：
```bash
source ~/.bashrc
```

以后：
```bash
proxyon
proxyoff
```

**临时生效（仅当前终端窗口）**
```bash
# HTTP/HTTPS 代理
export http_proxy=http://172.16.0.222:7897
export https_proxy=http://172.16.0.222:7897
# SOCKS5 全流量（ssh/部分工具需要）
export all_proxy=socks5://172.16.0.222:7897
# 大写变量兼容部分程序
export HTTP_PROXY=http://172.16.0.222:7897
export HTTPS_PROXY=http://172.16.0.222:7897
export ALL_PROXY=socks5://172.16.0.222:7897

# 本地/局域网跳过代理
export no_proxy="localhost,127.0.0.1,::1,192.168.0.0/16,172.16.0.0/12,10.0.0.0/8,.cluster.local,.svc"
export NO_PROXY="localhost,127.0.0.1,::1,192.168.0.0/16,172.16.0.0/12,10.0.0.0/8,.cluster.local,.svc"
```
测试连通：`curl https://www.google.com`

取消临时代理：
```bash
unset http_proxy https_proxy all_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY
```

**当前用户永久终端代理（重启终端仍生效）**
编辑 bash 配置：
```bash
nano ~/.bashrc
```
文件末尾粘贴上面全套 export 代码，保存退出（`Ctrl+O` → 回车 → `Ctrl+X`）
刷新生效：
```bash
source ~/.bashrc
```

**系统全局代理（所有用户、登录界面、systemd 服务）**
```bash
sudo nano /etc/environment
```
添加（**不要加 export**，直接键值对）：
```
http_proxy="http://127.0.0.1:7897"
https_proxy="http://127.0.0.1:7897"
all_proxy="socks5://127.0.0.1:7897"
no_proxy="localhost,127.0.0.1,::1,192.168.*"
HTTP_PROXY="http://127.0.0.1:7897"
HTTPS_PROXY="http://127.0.0.1:7897"
ALL_PROXY="socks5://127.0.0.1:7897"
NO_PROXY="localhost,127.0.0.1,::1,192.168.*"
```
重启系统完整生效。

## 二、APT 软件源代理（apt update/install 单独配置）

APT 不读取环境变量，需单独配置文件：
```bash
sudo nano /etc/apt/apt.conf.d/proxy.conf
```
写入：
```ini
# HTTP 代理
Acquire::http::Proxy "http://127.0.0.1:7897";
Acquire::https::Proxy "http://127.0.0.1:7897";
# SOCKS5 代理（可选，需先装 apt-transport-socks）
# Acquire::socks::Proxy "socks5://127.0.0.1:7897";
```
有账号密码：`http://user:pass@127.0.0.1:7897`

删除 APT 代理：`sudo rm /etc/apt/apt.conf.d/proxy.conf`

## 三、Git 代理（拉取 GitHub/Gitee）

**临时单次克隆**
```bash
git -c http.proxy=http://127.0.0.1:7897 clone https://github.com/xxx.git
```

**全局永久 Git 代理**
```bash
# http/https
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897
# socks5
git config --global http.proxy socks5://127.0.0.1:7897
```

取消 Git 代理：
```bash
git config --global --unset http.proxy
git config --global --unset https.proxy
```

## 四、Docker 拉镜像代理（dockerd 服务走代理）

```bash
# 创建配置目录
sudo mkdir -p /etc/systemd/system/docker.service.d
sudo nano /etc/systemd/system/docker.service.d/http-proxy.conf
```
写入：
```ini
[Service]
Environment="HTTP_PROXY=http://127.0.0.1:7897"
Environment="HTTPS_PROXY=http://127.0.0.1:7897"
Environment="ALL_PROXY=socks5://127.0.0.1:7897"
Environment="NO_PROXY=localhost,127.0.0.1,192.168.0.0/16,.docker.internal"
```
重载并重启 Docker：
```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 五、Snap / ubuntu pro 代理

```bash
# 设置
sudo pro config set global_apt_http_proxy http://127.0.0.1:7897
sudo pro config set global_apt_https_proxy http://127.0.0.1:7897
# 取消
sudo pro config unset http_proxy
sudo pro config unset https_proxy
```

## 六、一键开关代理脚本（推荐）

创建脚本快速启用/关闭，不用反复改配置：
```bash
nano ~/proxy-switch.sh
```
内容：
```bash
#!/bin/bash
PROXY_HTTP="http://127.0.0.1:7897"
PROXY_SOCKS="socks5://127.0.0.1:7897"
NO_PROXY_LIST="localhost,127.0.0.1,::1,192.168.*"

if [ "$1" = "on" ]; then
    export http_proxy=$PROXY_HTTP
    export https_proxy=$PROXY_HTTP
    export all_proxy=$PROXY_SOCKS
    export no_proxy=$NO_PROXY_LIST
    export HTTP_PROXY=$PROXY_HTTP
    export HTTPS_PROXY=$PROXY_HTTP
    export ALL_PROXY=$PROXY_SOCKS
    export NO_PROXY=$NO_PROXY_LIST
    echo "✅ 代理已开启"
elif [ "$1" = "off" ]; then
    unset http_proxy https_proxy all_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY NO_PROXY
    echo "❌ 代理已关闭"
else
    echo "用法: source ~/proxy-switch.sh on/off"
fi
```
赋予执行权限：
```bash
chmod +x ~/proxy-switch.sh
```
使用：
```bash
# 开代理
source ~/proxy-switch.sh on
# 关代理
source ~/proxy-switch.sh off
```

## 常见问题

1. 图形界面设置代理后终端不生效：图形代理只给 GUI 程序，终端需单独配环境变量
2. apt update 不走代理：必须配置 `/etc/apt/apt.conf.d/proxy.conf`，环境变量无效
3. docker pull 失败：dockerd 是 systemd 服务，要单独配置 `docker.service.d`
4. 局域网 IP 无法访问：`no_proxy` 加上 `192.168.*` 或对应网段
5. 代理需要账号密码：格式 `http://用户名:密码@ip:端口`
