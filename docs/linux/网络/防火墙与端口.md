## ufw（Ubuntu 推荐）

```bash
# 放行单个 TCP 端口
sudo ufw allow 8080

# 放行端口范围
sudo ufw allow 8000:8100/tcp

# 查看规则与状态
sudo ufw status
sudo ufw status numbered

# 删除规则（按编号）
sudo ufw delete 1

# 启用 / 禁用
sudo ufw enable
sudo ufw disable
```

## iptables

```bash
# 放行 TCP 端口
sudo iptables -A INPUT -p tcp --dport 8080 -j ACCEPT

# 查看规则
sudo iptables -L -n
```

> 持久化：`iptables` 规则重启会丢失，可用 `iptables-persistent`（ufw 底层即基于 iptables，日常优先用 ufw）。
