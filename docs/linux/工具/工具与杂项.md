## 下载工具

### wget

```bash
# 默认下载到当前目录
wget http://nginx.org/download/nginx-1.14.0.tar.gz

# 递归抓取整站链接（谨慎使用）
wget -r -np -k http://example.com/
```

与 curl 区别：curl 由于可自定义各种请求参数，在模拟 web 请求方面更擅长；wget 由于支持 ftp 和 recursive，在下载文件方面更擅长。类比的话 curl 是浏览器，而 wget 是迅雷。

### curl

```bash
# 下载文件到当前目录（-O 保留远程文件名）
curl -O https://download.oracle.com/java/21/latest/jdk-21_windows-x64_bin.zip

# 发送 GET / POST 请求
curl https://api.example.com/health
curl -X POST -d '{"a":1}' https://api.example.com/x
```

## gcc 编译工具

```bash
# 安装
sudo apt install gcc

# 查看版本
gcc --version
```

## 路由器配置 / 内网穿透

**虚拟服务器**

外部网络可通过访问路由进入配好的本地主机。

**DMZ 主机**

父路由设备访问子路由的 ip 可进入子路由中配好的主机。

**DDNS**

给路由配置域名访问。
