## 分区与格式化

### GPT 分区

全新裸盘（无分区）、大于 2T 的磁盘，必须使用 **GPT** 分区表（MBR 最大只支持 2T）。

```bash
# 查看磁盘信息
parted /dev/sdb print

# 创建 GPT 分区表
parted /dev/sdb mklabel gpt

# 创建单个分区（占满全部空间）
parted /dev/sdb mkpart primary ext4 0% 100%

# 或指定大小（如 500G）
parted /dev/sdb mkpart primary ext4 0% 500G
```

也可用 `gdisk`（交互式，类似 fdisk 但专用于 GPT）。

### 分区对齐

> **2048 扇区对齐就是 4K 对齐。** `2048 × 512B = 1 MiB`，1 MiB 是所有常见 RAID 条带大小、SSD 页大小、4K 扇区的公倍数，比单纯 4K 对齐更通用。`parted` / `gdisk` 默认即对齐到 1 MiB，无需手动干预。

验证对齐：

```bash
parted /dev/sdb align-check optimal 1
# 输出 "1 aligned" 表示对齐正确

fdisk -l /dev/sdb
# Start 列应为 2048
```

### 格式化

```bash
mkfs.ext4 /dev/sdb1
# 或
mkfs.xfs /dev/sdb1
```

**ext4 vs xfs 对比：**

| 维度 | ext4 | xfs |
|------|------|-----|
| 定位 | 通用文件系统，Linux 默认选择 | 高性能 64 位日志文件系统 |
| 最大文件系统 | 1 EiB | 8 EiB |
| 最大单文件 | 16 TiB | 8 EiB |
| 大文件读写 | 一般 | **强项**，分配组并行 I/O |
| 大量小文件 | **更好** | 一般 |
| 缩容（shrink） | ✅ 支持 `resize2fs` | ❌ 不支持，只能扩容 |
| fsck 速度 | 较慢 | 更快（元数据日志设计） |
| 快照/COW | 不原生支持 | 不原生支持（需 LVM 层实现） |
| RHEL/CentOS | 支持 | **默认文件系统**（RHEL 7+） |
| Ubuntu/Debian | **默认** | 需额外安装 `xfsprogs` |

**选型建议：**

- **通用场景 / 系统盘 / 小文件多** → `ext4`
- **大文件存储 / 数据库 / 日志盘 / 媒体文件** → `xfs`
- **需要后续缩容** → 只能 `ext4`（xfs 不支持 shrink）
- **注意**：xfs 格式化后不能缩容，规划容量时需留足余量

### 获取 UUID

`fstab` 推荐使用 `UUID=xxxx` 而非设备名（`/dev/sdb1`），因为设备名可能随插拔顺序变化。

```bash
blkid /dev/sdb1
# 或查看所有块设备
blkid

# 含挂载点信息
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT,UUID /dev/sdb
```

## 挂载

### 临时挂载

手动挂载，重启失效：

```bash
mount /dev/sdb1 /mnt/data
# 或指定文件系统类型
mount -t ext4 /dev/sdb1 /mnt/data

# 卸载
umount /mnt/data
```

> 修改 `/etc/fstab` 后，可用 `mount -a` 立即挂载所有 fstab 条目（不含 `noauto`），无需重启即可验证配置是否正确。

### 固定挂载（/etc/fstab）

编辑 `/etc/fstab`，添加一行：

```text
UUID=xxxx-xxxx  /mnt/data  ext4  defaults,nofail,x-systemd.device-timeout=5  0  0
```

> **必须加 `nofail`**：即使磁盘没插或故障，系统也能正常开机，不会卡在启动阶段。  
> **同时加 `x-systemd.device-timeout=5`**：systemd 默认等待设备超时时间为 **90 秒**，加此参数可缩短到 5 秒，避免开机时长时间卡住。

写入后执行 `mount -a` 验证，或重启生效。

### systemd 按需自动挂载（推荐）

适合备份盘、冷数据盘等**不常访问**的场景：访问时自动挂载，空闲后自动卸载。

```text
# /etc/fstab
UUID=xxxx-xxxx  /mnt/backup  ext4  noauto,x-systemd.automount,x-systemd.idle-timeout-sec=300,nofail,x-systemd.device-timeout=5  0  0
```

| 参数 | 作用 |
|------|------|
| `noauto` | 开机不自动挂载 |
| `x-systemd.automount` | 首次访问目录时触发挂载 |
| `x-systemd.idle-timeout-sec=300` | 空闲 5 分钟后自动卸载 |
| `nofail` | 磁盘不存在时不阻塞启动 |
| `x-systemd.device-timeout=5` | 等待设备就绪的超时秒数（默认 90 秒） |

添加后执行 `systemctl daemon-reload` 生效。

验证 automount 是否就绪：

```bash
systemctl status mnt-backup.automount
# 或列出所有 automount 单元
systemctl list-units --type=automount
```

## 参考：fstab 参数速查

```text
UUID=xxxx  /挂载点  ext4  defaults,nofail  0  0
                               │           │  └─ dump(备份) 0=不备份
                               │           └─ fsck 顺序 0=不检查, 1=根分区, 2=其他
                               └─ 挂载选项
```

常用挂载选项：

| 选项 | 作用 |
|------|------|
| `defaults` | 等同于 `rw,suid,dev,exec,auto,nouser,async` |
| `nofail` | 设备不存在时不阻塞启动 |
| `noauto` | 开机不自动挂载（需配合 `x-systemd.automount` 或手动 `mount`） |
| `noatime` | 不更新文件访问时间，减少磁盘写入，适合 SSD |
| `x-systemd.device-timeout=5` | 等待设备就绪的超时秒数（默认 90 秒） |
