## 光标移动

| 快捷键   | 描述                       |
| -------- | -------------------------- |
| Ctrl + A | 光标移到行首               |
| Ctrl + E | 光标移到行尾               |
| Ctrl + F | 前移一个字符（同 →）       |
| Ctrl + B | 后移一个字符（同 ←）       |
| Alt + F  | 前移一个单词               |
| Alt + B  | 后移一个单词               |

## 删除 / 粘贴

| 快捷键   | 描述                                       |
| -------- | ------------------------------------------ |
| Ctrl + U | 删除光标到行首的内容                       |
| Ctrl + K | 删除光标到行尾的内容                       |
| Ctrl + W | 删除光标前的一个单词                       |
| Alt + D  | 删除光标后的一个单词                       |
| Ctrl + Y | 粘贴（yank）上次删除的内容                 |
| Ctrl + H | 删除光标前一个字符（同 Backspace）         |
| Ctrl + D | 删除光标下字符（行首时为 EOF，会退出 shell）|
| Ctrl + _ | 撤销                                       |

## 控制 / 搜索

| 快捷键   | 描述                                       |
| -------- | ------------------------------------------ |
| Ctrl + L | 清屏（同 `clear`）                         |
| Ctrl + C | 终止当前命令                               |
| Ctrl + Z | 挂起当前进程（`fg` 恢复）                  |
| Ctrl + R | 反向搜索历史命令                           |
| Ctrl + G | 退出搜索                                   |
| Ctrl + S | 暂停屏幕输出（`Ctrl + Q` 恢复）            |

## 历史扩展

| 写法    | 描述                              |
| ------- | --------------------------------- |
| `!!`    | 执行上一条命令（常用 `sudo !!`）  |
| `!n`    | 执行第 n 条历史命令               |
| `!$`    | 上一条命令的最后一个参数          |
| `!*`    | 上一条命令的所有参数              |

Tab 补全：输入前缀后按 `Tab` 自动补全命令 / 路径 / 文件名，双击 `Tab` 列出所有候选。

> 注：以上为 bash 默认（emacs 模式）快捷键。Alt 组合键在部分终端（如 macOS 终端、某些 SSH 客户端）需开启「将 Option 用作 Meta」或用 `Esc` 作前缀。
