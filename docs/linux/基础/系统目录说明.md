> 速查即可，不必硬记。按用途分组，遇到陌生路径先判断它属于哪一类。

### 启动与核心（系统启动必需）

| 目录 | 用途 |
|------|------|
| `/bin` | 最小系统可操作所需的基础命令 |
| `/boot` | 内核及引导加载所需文件 |
| `/lib` | 系统库（如 C 编译器库），内核模块也在此 |
| `/sbin` | 引导、修复、恢复系统用的管理员命令 |

### 设备与进程（运行时由系统维护）

| 目录 | 用途 |
|------|------|
| `/dev` | 终端、磁盘、调制解调器等设备项 |
| `/proc` | 内核与所有运行进程的虚拟文件系统（内存中） |
| `/sys` | 设备与内核对象的虚拟文件系统（补充 `/proc`） |

### 配置与用户

| 目录 | 用途 |
|------|------|
| `/etc` | 关键的启动文件与系统配置 |
| `/home` | 普通用户主目录 |
| `/root` | 超级用户（root）主目录 |
| `/media` | 可移动介质（U 盘等）的挂载点 |
| `/mnt` | 临时挂载点（手工挂载用） |

### 软件安装（只读的程序与资源）

| 目录 | 用途 |
|------|------|
| `/usr` | 次要文件与命令的层次结构（系统软件主目录） |
| `/usr/bin` | 大多数用户命令与可执行文件 |
| `/usr/sbin` | 不太关键的管理/修复命令 |
| `/usr/lib` | 标准程序使用的库与支持文件 |
| `/usr/include` | 编译 C 程序所需的头文件 |
| `/usr/share` | 跨系统共享的只读数据（含 locale、文档等） |
| `/usr/src` | 非本地软件包的源代码 |
| `/opt` | 可选的应用安装包（第三方整包软件） |
| `/usr/local` | 本地手动安装的软件（包管理器不动这里，目录结构与 `/usr` 类似） |

### 可变数据（随运行变化，需持久）

| 目录 | 用途 |
|------|------|
| `/var` | 系统专用数据与配置文件 |
| `/var/log` | 系统及各类服务日志 |
| `/var/spool` | 打印队列、邮件等假脱机目录 |
| `/var/tmp` | 临时空间（重启后保留，区别于 `/tmp`） |

### 临时

| 目录 | 用途 |
|------|------|
| `/tmp` | 临时文件，**每次重启即清空** |

> 提示：`/usr/local` 下的 `bin` / `etc` / `lib` / `sbin` / `src` 是对应子项的本地版，作用与 `/usr` 同名目录一致，只是归本地管理，故不再逐条展开。
