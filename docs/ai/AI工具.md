# AI / LLM 工具与框架

## [TextGrad](https://github.com/zou-group/textgrad)

- **类别**: LLM 优化 / 自动微分
- **功能**: 使用大型语言模型的文本反馈模拟梯度，进行类似反向传播的优化。
- **来源**: Nature 论文
- **备注**: 可以优化提示、生成文本、代码输出等复杂系统。

## [PydanticAI](https://github.com/pydantic/pydantic-ai)

- **类别**: LLM + 类型安全
- **功能**: 将 LLM 输出与 Pydantic 数据模型结合，实现类型安全、结构化数据解析。
- **用途**: LLM 输出 JSON 解析、接口数据校验
