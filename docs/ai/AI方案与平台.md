# AI 方案与平台

## 自托管的问答/知识库 AI 方案综览

| 方案                | 开源许可   | 核心特性                    | 部署复杂度 | 适用场景              |
| ------------------- | ---------- | --------------------------- | ---------- | --------------------- |
| Dify                | Apache-2.0 | 工作流、RAG、评测、插件生态 | 中         | 团队用的全栈 AI 平台  |
| FastGPT             | MIT        | 向量检索、数据集、聊天应用  | 低         | 快速搭建企业内问答    |
| AnythingLLM         | MIT        | 多源知识、RAG、前端面板     | 低         | 个人/小团队知识助理   |
| Open WebUI + RAG    | AGPL       | 本地模型、聊天、检索扩展    | 低         | Ollama 驱动的离线使用 |
| Haystack            | Apache-2.0 | RAG 管线、评估、组件化      | 中         | 可插拔、可复用的后端  |
| LlamaIndex + Chroma | 多样       | 向量化管线、索引抽象        | 中         | 定制化研发型团队      |
| Weaviate            | Apache-2.0 | 向量数据库、混合检索        | 中         | 大规模语义检索        |
| Milvus              | Apache-2.0 | 海量向量、集群/分片         | 中高       | 高并发、超大数据集    |
