# ai学习

## mcp 与 a2ui

MCP拿数据，A2UI决定怎么“给人看”

### MCP 的世界里（能力层）

- AI 调用：
  - DB
  - API
  - 文件系统
  - 内部服务
- 返回的是：
  - 数据
  - 执行结果
  - 状态

👉 **不关心 UI 怎么显示**



### A2UI 的世界里（UI 层）

- AI 操作：
  - 页面跳转
  - 打开弹窗
  - 表单填充
  - 高亮组件
- 不直接碰业务数据
- 不执行副作用（或极少）



### 它们在系统架构中的位置

```
用户
 ↓
UI（Vue / React）
 ↓  ↑  A2UI
Agent / LLM
 ↓  ↑  MCP
工具 / 服务 / DB
```

### 类比一下（帮助记忆）

| 类比     | MCP         | A2UI        |
| -------- | ----------- | ----------- |
| 人       | 手          | 表情 / 动作 |
| 操作系统 | syscall     | GUI 事件    |
| 后端     | Service API | View Model  |
| 自动驾驶 | 控制引擎    | 仪表盘      |
