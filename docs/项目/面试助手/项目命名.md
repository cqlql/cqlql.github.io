# 项目命名

项目命名

```
passup-backend          (Java)
passup-ai-service       (Python)
passup-frontend-pc
passup-frontend-mp
```

容器镜像命名

```
services:
  frontend-web: # Caddy + 静态资源
    container_name: passup-frontend-web

  backend-java: # 业务服务
    image: passup-backend-java
    container_name: passup-backend-java

  ai-service:
    image: passup-ai-service
    container_name: passup-ai-service

  postgres:
  redis:
  minio:

networks:
  passup-network:
```
