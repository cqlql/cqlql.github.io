## 各种端

| 场景                           | 推荐名称                       |
| ------------------------------ | ------------------------------ |
| 用户使用的小程序/APP对应的网站 | 用户端（User Portal）          |
| 普通用户访问的网站             | 前台（Frontend / Public Site） |
| 管理员使用的网站               | 管理后台（Admin Portal）       |
| 运营人员使用的网站             | 运营后台（Operations Portal）  |
| CMS后台                        | 管理控制台（Admin Console）    |
