> 历史存档：IE6 官方调试工具 "Microsoft SuperPreview" 原下载页已失效（[原链接](https://www.microsoft.com/en-us/download/details.aspx?id=2020)）。IE6 已基本淘汰，仅作记录。

## 替代调试方式

- **IE11 文档模式**：IE11 按 `F12` 打开开发者工具，在 `仿真 / 文档模式` 下拉选 `IE6 / 7 / 8` 模拟旧内核渲染，配合 `F12` 的 DOM 资源管理器、控制台排查。
- **IE Tester**：第三方工具，可在一台机器上切换 IE5.5~IE11 渲染（注意仅渲染近似，非真实内核）。
- **虚拟机**：微软官方提供各版本 IE 的免费 VM 镜像（[developer.microsoft.com/ie](https://developer.microsoft.com/ie/)），用于真实环境验证。
