---
title: 浏览器唤起桌面应用
sort: 52
---

通过自定义 URL 协议（URL Scheme）让浏览器点击链接唤起本地桌面应用（Windows）。

原理：在注册表中注册一个协议名（如 `eclassedu`），将其 `command` 指向本地 exe，之后 `eclassedu://` 链接即可拉起该应用。

注册表示例（保存为 `.reg` 双击导入）：

```
Windows Registry Editor Version 5.00
[HKEY_CLASSES_ROOT\eclassedu]
@=""
"URL Protocol"=""

[HKEY_CLASSES_ROOT\eclassedu\DefaultIcon]
@=""

[HKEY_CLASSES_ROOT\eclassedu\Shell]

[HKEY_CLASSES_ROOT\eclassedu\Shell\open]

[HKEY_CLASSES_ROOT\eclassedu\Shell\open\command]
@="\"D:\\Program Files (x86)\\教学易\\Eclassedu.exe\""
```

页面中使用：

```html
<a href="eclassedu://open?param=1">打开教学易</a>
```

> 注意：`URL Protocol` 必须为空字符串键，否则协议不生效。
