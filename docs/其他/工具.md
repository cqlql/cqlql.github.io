常用开发辅助工具速查。

## Postman 接口测试

- 请求模拟：选择 Method（GET/POST...）、填 URL、在 `Params` 加查询参数、`Headers` 加请求头、`Body` 选 `raw` + `JSON` 写请求体。
- 环境（Environment）：用变量 `{{base_url}}` 切换 dev/prod，避免改 URL。
- 鉴权：`Authorization` 选 `Bearer Token` / `Basic Auth` / `API Key`。
- 导出：`Collections` 可导出为 JSON 分享；`Runner` 可做简单批量/循环请求。
- 注意：Postman 的 `Pre-request Script` 用 JS 写，可做签名、取 token 等前置逻辑。
