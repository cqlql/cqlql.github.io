# SSH 文件传输

基于 SSH 的文件传输与同步工具专题。按使用场景选择：

| 工具 | 主要用途 | 特点 |
|------|----------|------|
| [SCP 文件传输](./SCP%20文件传输.md) | 简单文件复制 | 一次性拷贝，非增量 |
| [SFTP 文件传输](./SFTP%20文件传输.md) | 交互式文件传输 | 可浏览目录后再传 |
| [rsync 文件同步](./rsync%20文件同步.md) | 增量文件同步 | 只传差异、可断点续传 |

基础准备（免密传输）：[SSH 密钥管理](./SSH%20密钥管理.md)。远程登录基础见 [SSH 登录基础](./ssh%20登录基础.md)。

## 学习路径

- `scp` → "我要把这个文件传过去"
- `rsync` → "我要让这两个目录保持同步"
