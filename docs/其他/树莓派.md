# 树莓派

## 固定 IP（使用 cloud-init）

编辑配置文件

```bash
sudo nano /boot/user-data
```

内容示例

```bash
# cloud-config
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses: [192.168.1.100/24]   # 静态 IP 和子网掩码
      gateway4: 192.168.1.1           # 网关
      nameservers:
        addresses:
          - 114.114.114.114
          - 8.8.8.8
```

重启

```bash
sudo reboot
```
