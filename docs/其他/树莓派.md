## 一、准备工作（必做）

1. 查接口与网关：`ip a` 看接口（有线**eth0**、无线**wlan0**）；`ip route | grep default` 查网关（如 192.168.1.1）。
2. 选静态 IP：选路由器 DHCP 池外地址（如 192.168.1.100），避免冲突。
3. 备份配置：`sudo cp /etc/dhcpcd.conf /etc/dhcpcd.conf.bak`，方便回滚。

## 二、终端配置（dhcpcd.conf，推荐）

1. 编辑文件：`sudo nano /etc/dhcpcd.conf`。

2. 末尾添加配置（按接口改）：

```bash
# 有线eth0
interface eth0
static ip_address=192.168.1.100/24  # 静态IP/子网掩码
static routers=192.168.1.1          # 网关
static domain_name_servers=192.168.1.1 8.8.8.8  # DNS，空格分隔多个

# 无线wlan0（二选一）
interface wlan0
static ip_address=192.168.1.101/24
static routers=192.168.1.1
static domain_name_servers=192.168.1.1 8.8.8.8
```

3. 保存退出：Ctrl+X → Y → 回车。

5. 重启生效：`sudo systemctl restart dhcpcd` 或 `sudo reboot`。

7. 验证：`ip a` 确认 IP 已固定。
