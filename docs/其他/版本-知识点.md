## 版本号示例

```
v2.0.0-alpha.8
v15.0.0-beta.6
v15.0.0-rc.2
```

## 主.次.修订 含义

- 主版本号：重大更新、不兼容改动
- 子版本号：新增功能（向下兼容）
- 修正版本号：bug 修复（向下兼容）

## 预发布后缀（减号后面）

预发布后缀用来标识测试的阶段和范围：

- **alpha**：内测版本，开发团队内部或有限用户体验测试。
- **beta**：公测版本，面向所有用户公开测试。
- **rc（Release Candidate）**：正式发布候选版，beta 之后，通常已相对稳定、仅做少量修正。
