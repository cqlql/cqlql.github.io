## 版本号示例

```
v2.0.0-alpha.8
v15.0.0-beta.6
v15.0.0-rc.2
```

## 主.次.修订 含义

- 主版本号：重大更新、不兼容改动
- 子版本号：新增功能（向下兼容）
- 修正版本号：bug 修复（向下兼容）

## 预发布后缀（减号后面）

> 广义上对测试有三个传统的称呼：alpha、beta、gamma(rc)，用来标识测试的阶段和范围。
>
> - **alpha**：内测（CB），开发团队内部或有限用户体验测试版本。
> - **beta**：公测，针对所有用户公开的测试版本。
> - **gamma / rc（Release Candidate）**：正式发布候选版，beta 之后，一般是对 beta 做过一些修改。
>
> -- 摘自百度百科
