完整的 Spring Cloud：

```
Spring Boot
+ Spring Cloud
+ Docker
```

特点：

- 组件多
- 运维复杂



很多公司的实际架构：

```
Spring Boot
+ Docker
+ Kubernetes
+ OpenFeign
+ Resilience4j
+ Prometheus
+ Grafana
```

不会上完整 Spring Cloud。



**很多 Java 开发者都没意识到的事实**：

**Spring Cloud 的时代其实已经基本结束了。**

现在 Java 云原生真正的趋势其实是 **另一套架构体系**。
