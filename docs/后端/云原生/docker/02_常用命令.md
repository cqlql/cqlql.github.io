## 镜像指令

### 查看 docker 中已有镜像

```shell
docker images
```

### 查看未使用镜像（没有 tag）

```shell
docker images -f "dangling=true"
```

 这会显示没有 tag 和未被引用的镜像层（通常可以安全删除）。

### 查看未使用镜像（脚本）

```shell
#!/bin/bash

echo "正在查找未被容器使用的镜像..."

# 获取所有镜像的 ID 和名称（格式：ID 仓库:标签）
docker images --format '{{.ID}} {{.Repository}}:{{.Tag}}' | while read img_id img_name; do
    # 检查是否有容器使用该镜像
    used=$(docker ps -a --filter "ancestor=$img_id" --format '{{.ID}}')
    if [ -z "$used" ]; then
        echo "未使用镜像：$img_name ($img_id)"
    fi
done
```

## 容器指令

### 查看所有容器

```shell
docker ps -a
```

### 只查看运行中的容器

```shell
docker ps
```

### 进入容器内部

```shell
docker exec -it 289cc00dc5ed bash
```

### 删除容器

```shell
# 删除一个名为 trusting_newton 的容器
docker container rm trusting_newton
```

如果要删除一个运行中的容器，可以添加 `-f` 参数。
