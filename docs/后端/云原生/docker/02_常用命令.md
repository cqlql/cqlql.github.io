## 官方在线镜像仓库

https://hub.docker.com/

## 镜像指令

### 查看已有镜像

```shell
docker images
```

### 搜索镜像

```shell
docker search nginx
```

### 拉取镜像

```shell
docker pull nginx:latest
```

### 删除镜像

```shell
docker rmi <镜像ID或名称>
```

### 查看未使用的镜像（无 tag）

```shell
docker images -f "dangling=true"
```

这会显示没有 tag 和未被引用的镜像层，通常可以安全删除。

### 查找未被容器使用的镜像（脚本）

```shell
#!/bin/bash

echo "正在查找未被容器使用的镜像..."

# 获取所有镜像的 ID 和名称
docker images --format '{{.ID}} {{.Repository}}:{{.Tag}}' | while read img_id img_name; do
    # 检查是否有容器使用该镜像
    used=$(docker ps -a --filter "ancestor=$img_id" --format '{{.ID}}')
    if [ -z "$used" ]; then
        echo "未使用镜像：$img_name ($img_id)"
    fi
done
```

### 镜像导出与导入

```shell
# 导出镜像为 tar 文件
docker save -o nginx.tar nginx:latest

# 从 tar 文件导入镜像
docker load -i nginx.tar
```

## 容器指令

### 查看所有容器

```shell
docker ps -a
```

### 查看运行中的容器

```shell
docker ps
```

### 运行容器

```shell
# 基本运行
docker run -d --name my-nginx -p 8080:80 nginx:latest

# 参数说明：
#   -d              后台运行
#   --name          指定容器名称
#   -p 宿主机:容器   端口映射
#   -v 宿主机:容器   挂载数据卷
#   -e              设置环境变量
#   --restart       重启策略（no/always/on-failure/unless-stopped）
```

### 启动 / 停止 / 重启容器

```shell
docker start <容器名或ID>
docker stop <容器名或ID>
docker restart <容器名或ID>
```

### 进入容器内部

```shell
docker exec -it <容器名或ID> bash
# 或使用 sh（部分精简镜像无 bash）
docker exec -it <容器名或ID> sh
```

### 查看容器日志

```shell
# 查看全部日志
docker logs <容器名或ID>

# 实时跟踪日志（类似 tail -f）
docker logs -f <容器名或ID>

# 查看最近 N 行
docker logs --tail 50 <容器名或ID>
```

### 查看容器详细信息

```shell
docker inspect <容器名或ID>
```

### 删除容器

```shell
# 删除已停止的容器
docker rm <容器名或ID>

# 强制删除运行中的容器
docker rm -f <容器名或ID>

# 批量删除所有已停止的容器
docker container prune
```

### 容器与宿主机文件互传

```shell
# 从宿主机复制到容器
docker cp /宿主机/路径 <容器名>:/容器/路径

# 从容器复制到宿主机
docker cp <容器名>:/容器/路径 /宿主机/路径
```

## 网络

```shell
# 查看所有网络
docker network ls

# 创建网络
docker network create my-network

# 将容器连接到网络
docker network connect my-network <容器名>

# 断开容器与网络的连接
docker network disconnect my-network <容器名>

# 查看网络详情
docker network inspect my-network
```

## 数据卷

```shell
# 查看所有数据卷
docker volume ls

# 创建数据卷
docker volume create my-volume

# 删除数据卷
docker volume rm my-volume

# 清理未使用的数据卷
docker volume prune

# 查看数据卷详情
docker volume inspect my-volume
```

## 系统信息与统计

```shell
# 查看 Docker 系统信息
docker info

# 查看磁盘使用情况
docker system df

# 查看容器资源使用（CPU / 内存）
docker stats

# 一键清理（停止容器 + 删除未使用资源）
docker system prune -a
```
