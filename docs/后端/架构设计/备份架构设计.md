# 备份架构设计

```text
                Git
                 │
          保存所有 YAML
                 │
────────────────────────────────

每天凌晨

CronJob
    │
    ├──────────────┐
    │              │
pg_dump         Redis RDB
    │              │
    └──────┬───────┘
           │
      压缩（可选）
           │
      上传 MinIO
           │
           ▼
     Backup Bucket
           │
           ▼
  再同步到另一台服务器/NAS（异地更佳）
```

- **数据库备份与 K3s 解耦**，即使未来迁移到 Docker Compose、虚拟机或云数据库，备份方案也无需改变。
- **PostgreSQL 使用原生备份工具**，保证一致性和可恢复性。
- **Redis 根据用途决定是否备份**，避免做无意义的数据备份。
- **K3s 只负责调度备份任务（CronJob）和备份集群自身的 etcd**，职责清晰。
- **备份至少保留两份**：一份在对象存储（如 MinIO），另一份同步到独立服务器或 NAS，避免单点故障。
