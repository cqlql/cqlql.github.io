## 镜像加速

新增 daemon 文件，这是Docker 守护进程的配置文件。

```bash
sudo nano /etc/docker/daemon.json
```

加入以下内容：（[目前国内可用Docker镜像源汇总](https://github.com/dongyubin/DockerHub?tab=readme-ov-file)）

```json
{ 
  "registry-mirrors": [
    "https://docker.xpg666.xyz",
    "https://docker.1ms.run",
    "https://dytt.online"
   ]
}
```

重新加载 docker

```bash
sudo systemctl daemon-reexec
sudo systemctl reload docker
```

查看是否配置成功

```bash
sudo docker info
```

如果成功，会多出 `Registry Mirrors:`字段，并可以从中找到你设置的值



测试镜像拉取。最后一行会注明拉取地址

```bash
docker pull hello-world
# hello-world 一般都能拉取成功，显示拉取地址是 docker.io/library/hello-world:latest，这个地址似乎没有被墙
# 或者直接拉取 kibana，将从 https://registry-1.docker.io/v2/ 拉取，一般会失败
docker pull kibana
```

## 代理

Docker **不会自动使用系统代理**。

需要显式配置：

```
sudo mkdir -p /etc/systemd/system/docker.service.d
sudo nano /etc/systemd/system/docker.service.d/http-proxy.conf
```

```plain
[Service]
Environment="HTTP_PROXY=http://172.16.0.222:7890"
Environment="HTTPS_PROXY=http://172.16.0.222:7890"
Environment="NO_PROXY=localhost,127.0.0.1"
```

重启：

```plain
sudo systemctl daemon-reload
sudo systemctl restart docker
```
