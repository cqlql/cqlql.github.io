# 容器跨网段访问不通排查

> 该问题的排查笔记已归档到通用 Docker 笔记中，详见：

👉 [云原生/docker/11_容器跨网段访问排查.md](../../云原生/docker/11_容器跨网段访问排查.md)

## 一句话回顾

容器能 ping 通同网段（`172.16.0.x`）却 ping 不通另一网段（`10.0.1.x`），宿主机都能通 —— 根因是跨网段**回程路由丢失**（容器经 NAT 出得去，但目标网段回包回不到 Docker 内网段）。

CI runner 场景踩坑时，重点看两个诱因：

1. Docker 网络重建导致网段漂移，网关上的回程路由指向了旧网段；
2. 自定义 Docker 网络用了 `10.0.0.0/8` 这类和内网重叠的大网段，抢走了真实内网的路由。
