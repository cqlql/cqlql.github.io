# MySQL 常用数据类型速查

## 整数

| 类型      | 字节 | 有符号范围            | 无符号范围         |
| --------- | ---- | --------------------- | ------------------ |
| TINYINT   | 1    | -128 ~ 127            | 0 ~ 255            |
| SMALLINT  | 2    | -32768 ~ 32767        | 0 ~ 65535          |
| INT       | 4    | ±21 亿                | 0 ~ 42 亿          |
| BIGINT    | 8    | ±9.2e18               | 0 ~ 1.8e19         |

- 主键/自增常用 `BIGINT`；金额禁用 `FLOAT/DOUBLE`，用 `DECIMAL`。

## 字符串

| 类型       | 说明                                   |
| ---------- | -------------------------------------- |
| CHAR(n)    | 定长，尾部补空格，适合短且定长（如 MD5）|
| VARCHAR(n) | 变长，最常用，n 为字符数               |
| TEXT       | 长文本，不可设默认值（5.7 前）         |
| JSON       | MySQL 5.7+ 原生 JSON 类型              |

## 时间

| 类型      | 说明                          |
| --------- | ----------------------------- |
| DATE      | 年月日                        |
| DATETIME  | 年月日时分秒，与时区无关      |
| TIMESTAMP | 时间戳，受时区影响，范围较小  |
| BIGINT    | 存毫秒时间戳（跨系统常用）    |

## 小数

```sql
DECIMAL(10, 2)  -- 共10位，小数2位，精确
```

> [!tip]
> 存密码不要用 `CHAR/VARCHAR` 明文，应存加盐哈希（如 bcrypt）；原示例 `CHAR(45)` 仅作结构演示。
