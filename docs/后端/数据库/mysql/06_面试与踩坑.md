# MySQL 面试与踩坑速记

## 索引 ≠ 约束

- `PRIMARY / UNIQUE`：索引 + 约束
- `INDEX`：只有索引
- `FOREIGN KEY`：只有约束，不自动建索引，JOIN 性能差时要手动加

## password() 已废弃

- MySQL 8 移除了 `PASSWORD()` 函数，修改密码用：
  ```sql
  ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '新密码';
  ```

## UPDATE / DELETE 忘了 WHERE

- 不带 `WHERE` 会作用于全表；生产务必先 `SELECT` 确认影响行数。

## 字符集与排序

- 统一用 `utf8mb4` + `utf8mb4_0900_ai_ci`（MySQL 8 默认），`utf8` 实为 3 字节，存不了 emoji。

## 自增主键用 BIGINT

- `INT` 上限约 21 亿，大表容易溢出；主键自增推荐 `BIGINT UNSIGNED`。

## 隐式类型转换导致索引失效

```sql
-- phone 是 VARCHAR，下面写法会让索引失效
SELECT * FROM t WHERE phone = 13800000000;
-- 正确：
SELECT * FROM t WHERE phone = '13800000000';
```

## 深分页性能差

```sql
-- 慢：OFFSET 越大越慢
SELECT * FROM t ORDER BY id LIMIT 10 OFFSET 1000000;
-- 游标分页（基于上一页 last id）：
SELECT * FROM t WHERE id > 1000000 ORDER BY id LIMIT 10;
```

## 事务与隔离级别

- 默认 `REPEATABLE READ`；读已提交用 `READ COMMITTED`。
- 长事务会拖住 undo 日志，导致表空间膨胀。
