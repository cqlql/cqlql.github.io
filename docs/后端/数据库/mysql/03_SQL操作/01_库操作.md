## 创建库

```sql
CREATE DATABASE IF NOT EXISTS `db_user`
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_0900_ai_ci;
```

## 查看所有库

```sql
SHOW DATABASES;                 -- 权限内所有库
SHOW DATABASES LIKE '%db_user'; -- 过滤
```

## 删除库

```sql
DROP DATABASE IF EXISTS db_user;
```
