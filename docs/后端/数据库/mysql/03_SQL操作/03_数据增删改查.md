## 插入

```sql
INSERT INTO `user` (username, password, nickname)
  VALUES ('joly', '123123', '张三');

-- 批量
INSERT INTO `user` (username, nickname)
  VALUES ('a', '阿'), ('b', '必');

-- 冲突忽略 / 更新（UPSERT）
INSERT INTO `user` (uid, nickname) VALUES ('u1', '旧')
  ON DUPLICATE KEY UPDATE nickname = '新';
```

## 更新

```sql
UPDATE `user` SET nickname = '李四' WHERE id = 1;
-- 务必带 WHERE，否则全表更新
```

## 删除

```sql
DELETE FROM `user` WHERE id = 2;
-- 务必带 WHERE，否则全表删除
-- 清空整表（不可回滚、不触发行级触发器，速度快）：
TRUNCATE TABLE `user`;
```

## 查询

```sql
SELECT * FROM `user`;                       -- 全量
SELECT id, nickname FROM `user` WHERE id=1; -- 指定列
SELECT * FROM `user` ORDER BY id DESC LIMIT 10 OFFSET 0;
SELECT COUNT(*) FROM `user`;
```

> [!warning]
> `UPDATE` / `DELETE` 不带 `WHERE` 会作用于全表，生产环境务必先确认。
