## 服务控制（systemctl）

```sh
systemctl status mysql     # 查看状态
systemctl start mysql      # 启动
systemctl stop mysql       # 停止
systemctl restart mysql    # 重启
```

> WSL 环境若无 systemctl，可用 `sudo service mysql start`。

## 登录

```sh
# 稍后输入密码（推荐，密码不明文）
mysql -uroot -p

# 直接带明文密码（不安全）
mysql -uroot -p123123
```

## 查看端口

在 MySQL 内执行：

```sql
SHOW GLOBAL VARIABLES LIKE 'port';
```

## 查找安装目录

```sh
sudo find / -path /mnt -prune -o -name mysql -print
```
