## 登录语法

```sh
mysql -u<用户名> -p[密码]
```

## 查看所有用户

```sql
SELECT user, host FROM mysql.user;
```

## 新建用户

```sql
CREATE USER 'joly'@'%' IDENTIFIED BY '新密码';
-- % 表示任意 host；可改为 'localhost' 仅本地访问
-- 不带 IDENTIFIED BY 则无密码（不推荐）
```

## 修改用户 host

```sql
UPDATE mysql.user SET host = '%' WHERE user = 'root';
FLUSH PRIVILEGES;
```

## 删除用户

```sql
DROP USER 'jack'@'localhost';
```

## 修改密码（MySQL 8）

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '新密码';
FLUSH PRIVILEGES;
```

> [!warning]
> 旧版 `UPDATE mysql.user SET authentication_string=PASSWORD('xxx')` 中的 `PASSWORD()` 函数在 **MySQL 8 已移除**，不要再用。

## 权限管理

```sql
SHOW GRANTS FOR 'joly'@'%';                    -- 查看权限
GRANT ALL ON db_user.* TO 'joly'@'%';          -- 授权某库
REVOKE ALL ON db_user.* FROM 'joly'@'%';       -- 回收权限
FLUSH PRIVILEGES;
```
