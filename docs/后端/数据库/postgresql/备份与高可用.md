# PostgreSQL 数据备份与高可用方案

## 一、数据安全：备份方案

### 1\. 全量备份：pg\_dump

数据量不大、业务简单的小型项目。

### 2\. 增量备份：Base Backup \+ WAL

- 数据库数据量较大（≥50\~100GB）；

- 业务数据安全性要求高，**无法接受单日数据丢失**；

- 需要支持**精准时间点恢复**（可恢复至任意分钟级节点）。

## 二、服务连续性：高可用方案（HA）

### 核心方案：Patroni（生产级推荐 ⭐）

全自动高可用--实现数据库节点自动故障检测、自动主从切换、自动恢复，无需人工干预，保障业务服务持续可用，有效避免单点故障导致的服务中断。

## 三、方案选型总结

|需求场景|推荐方案|核心优势|
|---|---|---|
|小型项目、数据量小、无需精准恢复|pg\_dump 全量备份|简单易用、低成本、零复杂度|
|Base Backup \+ WAL 增量备份|高效备份、精准时间点恢复、数据安全性高||
|Patroni 高可用架构|全自动故障转移、杜绝单点故障、服务稳定性强||
