## 循环遍历
```bash
res = [
    [
        [[28.0, 37.0], [302.0, 39.0], [302.0, 72.0], [27.0, 70.0]],
        ("纯臻营养护发素", 0.9978227019309998),
    ],
    [
        [[26.0, 83.0], [173.0, 83.0], [173.0, 104.0], [26.0, 104.0]],
        ("产品信息/参数", 0.9899477362632751),
    ],
    [
        [[27.0, 112.0], [331.0, 112.0], [331.0, 135.0], [27.0, 135.0]],
        ("（45元/每公斤，100公斤起订）", 0.9662042260169983),
    ],
]
# 方法1：使用 for 循环
filtered_res = []
for item in res:
    text, confidence = item[1]  # 解构出文本和置信度
    if confidence >= 0.9:
        filtered_res.append(item)

# 方法2：使用列表推导式（更简洁）
texts_only = [item[1][0] for item in res if item[1][1] >= 0.9]
filtered_data = [(item[1][0], item[1][1]) for item in res if item[1][1] >= 0.9]
```
