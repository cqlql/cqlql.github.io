## （MIME 类型）汇总：
| 文件类型 | MIME 类型 |
| --- | --- |
| .docx (Word) | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| .xlsx (Excel) | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| .pptx (PowerPoint) | `application/vnd.openxmlformats-officedocument.presentationml.presentation` |
| .pdf | `application/pdf` |
| .doc (旧版 Word) | `application/msword` |
| .xls (旧版 Excel) | `application/vnd.ms-excel` |
| .ppt (旧版 PowerPoint) | `application/vnd.ms-powerpoint` |
| .txt (纯文本) | `text/plain` |
| .csv | `text/csv` |
| .json | `application/json` |
| .zip | `application/zip` |
| .png | `image/png` |
| .jpg/.jpeg | `image/jpeg` |
| .gif | `image/gif` |


## 从文件名获取后缀
```python
from pathlib import Path
file_ext = Path(file.filename).suffix.lower()
```

## 文件名使用新后缀
```python
tmp_pdf_path = Path(f"{temp_dir}/{tmp_file_name}")
tmp_pdf_path.with_suffix(".docx")
```

##  临时文件
```python
chunk_size: int = 1024 * 1024
with tempfile.NamedTemporaryFile(delete=False, suffix=".pdf") as tmp_pdf:
    # 分块写入临时文件
    while chunk := await file.read(chunk_size):
        tmp_pdf.write(chunk)
        tmp_pdf_path = Path(tmp_pdf.name)
```

## 文件删除
```python
tmp_file_path = Path(tmp_file.name)
tmp_file_path.unlink(missing_ok=True)
```
