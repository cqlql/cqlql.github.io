## pip
### 配置镜像加速
#### 临时使用镜像源
添加 -i 选项，指定镜像源地址

```bash
pip install 包名 -i https://mirrors.aliyun.com/pypi/simple/
```

#### 永久配置镜像源（推荐）
```bash
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
```

#### <font style="color:rgb(0, 0, 0) !important;">验证是否生效</font>
```bash
pip config list
```

#### 国内常用的镜像源地址
+ 阿里云：`https://mirrors.aliyun.com/pypi/simple/`
+ 清华大学：`https://pypi.tuna.tsinghua.edu.cn/simple`
+ 中国科学技术大学：`https://pypi.mirrors.ustc.edu.cn/simple/`
+ 豆瓣：`https://pypi.doubanio.com/simple/`



## [pipx](https://pipx.pypa.io/stable/)
主要用于安装可全局运行的 Python CLI 工具

隔离环境：每个工具安装在独立的虚拟环境中，避免依赖冲突

全局可用：安装后的工具可以直接在终端运行，无需激活虚拟环境。

```bash
# 使用 pip 安装（用户级）
python3 -m pip install --user pipx
# 将 pipx 添加到 PATH
python3 -m pipx ensurepath
# 验证安装
pipx --version
# 查看 PyPI 上的最新版本
pip index versions pipx
# 升级 pipx
pipx upgrade pipx
```

注：ubuntu 推荐用 apt 安装 pipx，但可能不是最新

## poetry
可用的依赖管理工具有：<font style="color:#DF2A3F;">Poetry</font>（推荐）、pip-tools、Hatch、Pipenv、pip、Conda / Mamba、PDM

### 安装
```bash
# 使用 pipx 安装（推荐）
pipx install poetry
```

### 初始化项目
```bash
poetry init  
```

### 配置虚拟环境（可选）
Poetry 默认自动创建虚拟环境，路径通常为 {cache-dir}/virtualenvs。

手动指定虚拟环境路径

```bash
poetry config virtualenvs.in-project true  # 在项目目录下创建 `.venv`
```

### 安装依赖
```bash
# 生产依赖
poetry add django gunicorn  
# 开发依赖
poetry add --dev pytest mypy  
```

### 运行脚本
```bash
poetry run python script.py  
```

或激活虚拟环境后直接运行：

```bash
poetry shell  # 激活虚拟环境
python script.py
exit  # 退出虚拟环境
```

### 打包
打包后将生成

源码包（sdist）：.tar.gz 格式

Wheel 包（wheel）：.whl 格式，可直接通过 pip install 安装

```bash
poetry build
```

#### 部署Wheel 包
**FastAPI 项目**

安装

```bash
poetry run pip install your_project-0.1.0-py3-none-any.whl
```

运行

```bash
# 开发模式
poetry run uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 生产模式
poetry add gunicorn uvloop httptools
poetry run gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app -b 0.0.0.0:8000
```

Systemd 托管

创建服务文件 /etc/systemd/system/your_project.service：

```bash
[Unit]
Description=Your Web Project
After=network.target

[Service]
User=www-data
WorkingDirectory=/path/to/your_project
ExecStart=/path/to/poetry run gunicorn -w 4 -b unix:/tmp/your_project.sock "your_project:app"
Restart=always

[Install]
WantedBy=multi-user.target
```

<font style="color:rgb(64, 64, 64);">然后启用服务：</font>

```bash
sudo systemctl daemon-reload
sudo systemctl start your_project
sudo systemctl enable your_project
```

## uv
[uv 官方文档](https://docs.astral.sh/uv/)

### 安装
#### pipx 安装（隔离环境，可全局运行）
```shell
pipx install uv
```

#### 直接当前 pip 虚拟环境下安装（推荐）
也就是说，兼容 pip项目。这种方式比较方便，推荐

```shell
pip install uv
```

#### windows 下直接使用exe
[下载 exe文件 ](https://github.com/astral-sh/uv/releases)，将下载好的文件设置环境变量，即可在现有项目下使用 `uv sync`，会自动创建python虚拟环境。

### 创建项目
会创建 <font style="color:rgb(54, 70, 78);background-color:rgb(245, 245, 245);">pyproject.toml</font> 等基本文件

```shell
uv init
```

### 设置国内源
1. 设置环境变量:

可以通过设置环境变量 UV_DEFAULT_INDEX 来指定默认的包索引源。例如，可以将其设置为清华大学的 PyPI 镜像源：

```bash
export UV_DEFAULT_INDEX=https://mirrors.aliyun.com/pypi/simple/
```

2. 修改配置文件

 对于 Linux 和 macOS，配置文件通常位于 ~/.config/uv/uv.toml，而在 Windows 系统中，路径为 %APPDATA%/uv/uv.toml。如果路径不存在，可以手动创建该文件。

```toml
index-url = "https://mirrors.aliyun.com/pypi/simple/"
```

3. 修改当前项目的pyproject.toml

```toml
[tool.uv]
index-url = "https://mirrors.aliyun.com/pypi/simple/"
```

4. 临时使用镜像源:

```bash
uv add package_name --index-url https://mirrors.aliyun.com/pypi/simple/
```

阿里云镜像: https://mirrors.aliyun.com/pypi/simple/

### 安装依赖
如果没有，默认会创建 .venv 虚拟环境

添加新依赖项。加 `-v` 可以看到更详细的信息

```bash
uv add httpx
```

在现有环境下安装。比如刚从git下载的python项目，此时还没有安装依赖

```shell
uv sync
```

### 安装依赖--多源
该参数告诉 uv：“允许从所有源中找兼容版本（不只看第一个）。”

```typescript
uv sync --index-strategy unsafe-best-match
```

项目下的 pyproject.toml 配置多源

```typescript
[project]
name = "xdt-ai-ocr"
version = "0.1.0"
description = "OCR Service"
readme = "README.md"
requires-python = ">=3.12"
dependencies = [
    "paddlepaddle-gpu~=3.2.0"
]
[tool.uv]
index-url = "https://mirrors.aliyun.com/pypi/simple/"
extra-index-url = ["https://www.paddlepaddle.org.cn/packages/stable/cu126/"]
```

### 依赖版本控制
[参考文档](https://docs.astral.sh/uv/concepts/projects/dependencies/#project-dependencies)

```toml
[project]
name = "albatross"
version = "0.1.0"
dependencies = [
  # Any version in this range
  "tqdm >=4.66.2,<5",
  # Exactly this version of torch
  "torch ==2.2.2",
  # Install transformers with the torch extra
  "transformers[torch] >=4.39.3,<5",
  # Only install this package on older python versions
  # See "Environment Markers" for more information
  "importlib_metadata >=7.1.0,<8; python_version < '3.10'",
  "mollymawk ==0.1.0"
]
```
