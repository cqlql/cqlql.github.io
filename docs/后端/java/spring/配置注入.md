# 配置注入方式

单个简单值可用，其他情况推荐 `@ConfigurationProperties`

```java
@Component
public class JwtUtil {

    private final String secret;
    private final SecretKey key;

    public JwtUtil(@Value("${jwt.secret}") String secret) {
        this.secret = secret;
        this.key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }
}
```
### setter -> 写入 static

能跑，但属于反模式（不推荐，团队里应该禁止）

```java
@Component
public class Config {

    public static String API_APP_ID;

    @Value("${doubao.realtime.api-app-id}")
    public void setApiAppId(String value) {
        API_APP_ID = value;
    }
}
```

## @ConfigurationProperties（推荐主流）

更好维护，类型安全

```java
@Component
@Validated
@ConfigurationProperties(prefix = "doubao.realtime")
public class DoubaoRealtimeConfig {
    @NotBlank(message = "豆包ASR AppID 不能为空")
    private String apiAppId;
    private String apiAccessKey;
    private String apiAppKey;

    // getter setter
}
```
### `@ConfigurationProperties + @Bean`

符合 Spring 设计，**适合中大型项目**

Properties

```java
@ConfigurationProperties(prefix = "jwt")
@Validated
public record JwtProperties(@NotBlank String secret) {}
```

Config

```java
@Configuration
@EnableConfigurationProperties(JwtProperties.class)
public class JwtConfig {}
```
✅ 优势

- 配置类 ≠ 组件（解耦）
- 更符合 Spring 设计
- **适合中大型项目**

### 构造器绑定（Constructor Binding）

```java
@ConfigurationProperties(prefix = "jwt")
public class JwtProperties {

    private final String secret;

    public JwtProperties(String secret) {
        this.secret = secret;
    }

    public String getSecret() {
        return secret;
    }
}
```
👉 Spring Boot 2.2+ 支持

✅ 优势

- 不可变对象（更安全）
- 避免 setter
- 更偏函数式 / clean code

### 配置校验（非常推荐）

👉 启动时直接校验，防止配置错误

```java
@ConfigurationProperties(prefix = "jwt")
@Validated
public class JwtProperties {

    @NotBlank
    private String secret;
}
```

## 其他

### `Environment`（被很多人忽略）

```java
@Autowired
private Environment env;

String secret = env.getProperty("jwt.secret");
```

 适合场景

- 框架级 / 基础设施代码
- 动态读取（不想绑定成对象）

❌ 不适合

- 业务代码（可读性差）

### `Binder`（底层黑科技）

框架开发，非 Spring Bean 场景。👉 本质就是 `@ConfigurationProperties` 的底层实现

```java
Binder binder = Binder.get(environment);

JwtProperties props = binder.bind("jwt", JwtProperties.class).get();
```

 适合

- 框架开发
- 动态绑定
- 非 Spring Bean 场景

👉 本质就是 `@ConfigurationProperties` 的底层实现

### System.getProperty / env

```java
System.getProperty("jwt.secret");
System.getenv("JWT_SECRET");
```

 适合：

- JVM 参数
- 容器环境变量（Docker/K8s）

👉 实际生产中很常见（尤其云原生）

## 终极对比图（建议放 docs）

| 方式                       | 推荐度 | 场景     |
| -------------------------- | ------ | -------- |
| `@Value`                   | ⭐⭐     | 小配置   |
| `@ConfigurationProperties` | ⭐⭐⭐⭐⭐  | 主流     |
| `Environment`              | ⭐⭐     | 动态读取 |
| `@Bean + Properties`       | ⭐⭐⭐⭐⭐  | 架构推荐 |
| Constructor Binding        | ⭐⭐⭐⭐⭐  | 强烈推荐 |
| Binder                     | ⭐      | 框架开发 |
| System/env                 | ⭐⭐⭐    | 云原生   |
