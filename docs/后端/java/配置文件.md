## application.yml

### on-profile 参数

表示这个配置文件叫 prod，

```yml
# application-prod.yml
spring:
  config:
    activate:
      on-profile: prod
```

通过 application.yml 的 active 激活

```yml
# application.yml
spring:
  profiles:
    active: prod,local
```

也就是说，application.yml 是肯定会加载的， spring.profiles.active 决定再加载哪个文件，也可加载多个

也可在启动时指定 spring.profiles.active 参数

```
java -jar app.jar --spring.profiles.active=prod,swagger,common
```

### 环境变量语法**`${VAR}`**

```
spring:
  config:
    activate:
      on-profile: prod
  datasource:
    url: ${DB_URL}
    username: ${DB_USER}
    password: ${DB_PASSWORD}
```

在服务器上启动时，通过环境变量传入真值：

```bash
export DB_URL=jdbc:mysql://10.0.0.1:3306/mydb
export DB_USER=admin
export DB_PASSWORD=your_real_password
java -jar app.jar
```

#### 也可以通过 -D 的方式设置环境变量

```
java -Denv=prod -jar app.jar
```
`-Denv=prod` 本质是 **JVM System Property**

等价于：

```
System.setProperty("env", "prod");
```
如果你只是想切换环境，Spring 官方推荐用： spring.profiles.active

```
java -jar app.jar --spring.profiles.active=prod
```

#### ✅ 方式 1：直接在 application.yml 里用

```
my:
  env: ${env:dev}
```

解释：

- `${env}` → 读取 JVM 参数 `-Denv`
- `:dev` → 如果没传默认 dev

------

#### ✅ 方式 2：@Value 读取

```
@Value("${env}")
private String env;
```

------

#### ✅ 方式 3：Environment 读取（推荐）

```
@Autowired
private Environment environment;

String env = environment.getProperty("env");
```

#### Spring Boot 的参数优先级来源

Spring Boot 会自动把以下内容全部加载进 `Environment`：

1. JVM 参数（`-Dxxx=...`）
2. 操作系统环境变量（`export XXX=...`）
3. `application.yml`
4. 命令行参数（`--xxx=...`）
