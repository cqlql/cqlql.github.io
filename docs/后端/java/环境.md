# JDK 与 Maven 环境配置

## spring 启动

```javascript
mvn spring boot:run
```

mvn 命令需要全局安装 Maven。如果没有全局安装，也可以这样启动

```javascript
# Linux / macOS
./mvnw spring-boot:run

# Windows
mvnw.cmd spring-boot:run
```

`mvnw` 和 `mvnw.cmd` 是 **Maven Wrapper**（Maven 包装器）的启动脚本，用来让你在没有全局安装 Maven的情况下，也能运行项目里的 Maven 构建命令，并且保证大家用的 Maven 版本一致。 

通常更推荐 Maven Wrapper，这样可以严格控制 Maven版本，特别是在团队协作和持续集成（CI/CD）场景下。

## **Maven**

### 安装（Maven Wrapper 方式）

通过配置 `.mvn\wrapper\maven-wrapper.properties` 便会自动下载，这种方式可以严格控制 Maven版本，不同项目都是独立的 Maven

```
wrapperVersion=3.3.2
distributionType=only-script
# distributionUrl=https://repo.maven.apache.org/maven2/org/apache/maven/apache-maven/3.9.14/apache-maven-3.9.14-bin.zip
distributionUrl=https://maven.aliyun.com/repository/central/org/apache/maven/apache-maven/3.9.14/apache-maven-3.9.14-bin.zip
```

### 镜像加速

```bash
mkdir -p ~/.m2
cat > ~/.m2/settings.xml <<'EOF'
<settings>
    <mirrors>
        <mirror>
            <id>aliyunmaven</id>
            <mirrorOf>central</mirrorOf>
            <name>阿里云公共仓库</name>
            <url>https://maven.aliyun.com/repository/public</url>
        </mirror>
    </mirrors>
</settings>
EOF
```

> 粘贴后直接回车即可生成 `~/.m2/settings.xml`，Maven 后续下载依赖会自动走阿里云镜像。

## jdk自动安装脚本

### install_jdk.sh

```bash
#!/usr/bin/env bash
set -e

# 用户可修改的参数
# Eclipse Temurin 21（Linux x64，hotspot）。下载来源：https://adoptium.net/zh-CN/temurin/releases
# 可在上述页面自行替换为其他版本/架构的下载地址
JDK_URL="https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.5%2B11/OpenJDK21U-jdk_x64_linux_hotspot_21.0.5_11.tar.gz"
INSTALL_DIR="$HOME/opt/jdk"
PROFILE_FILE="$HOME/.bashrc"

# 颜色输出
green() { echo -e "\033[32m$1\033[0m"; }
yellow() { echo -e "\033[33m$1\033[0m"; }

# 确保安装目录存在
mkdir -p "$INSTALL_DIR"
cd "$INSTALL_DIR"

# 根据 URL 自动获取文件名
FILE_NAME=$(basename "$JDK_URL")
# 从 Temurin 的 URL 中提取主版本号（如 temurin21 -> 21）
JDK_VERSION=$(echo "$JDK_URL" | grep -oP '(?<=temurin)[0-9]+')
green "准备安装 JDK 版本: $JDK_VERSION"

# 检查是否已有 Java
if command -v java >/dev/null 2>&1; then
    CURRENT_VERSION=$(java -version 2>&1 | head -n 1 | awk -F '"' '{print $2}')
    yellow "当前已安装 Java: $CURRENT_VERSION"
fi

# 下载 JDK
if [[ ! -f "$FILE_NAME" ]]; then
    green "正在下载 $JDK_URL ..."
    curl -L -o "$FILE_NAME" "$JDK_URL"
else
    yellow "发现已下载的 JDK 包，跳过下载。"
fi

# 解压 JDK
green "解压 JDK ..."
tar -xzf "$FILE_NAME"

# 找到解压后的目录（jdk-21.*）
JDK_DIR=$(find "$INSTALL_DIR" -maxdepth 1 -type d -name "jdk-$JDK_VERSION*")
if [[ -z "$JDK_DIR" ]]; then
    echo "解压失败，未找到 JDK 目录！" >&2
    exit 1
fi

# 配置环境变量
if ! grep -q "JAVA_HOME=$JDK_DIR" "$PROFILE_FILE"; then
    green "配置 JAVA_HOME 到 $PROFILE_FILE ..."
    {
        echo ""
        echo "# Java JDK $JDK_VERSION"
        echo "export JAVA_HOME=$JDK_DIR"
        echo 'export PATH=$PATH:$JAVA_HOME/bin'
    } >> "$PROFILE_FILE"
else
    yellow "JAVA_HOME 已在 $PROFILE_FILE 中配置，跳过。"
fi

green "安装完成！请运行以下命令让配置生效："
echo "    source $PROFILE_FILE"
green "然后检查版本："
echo "    java -version"
```

### install_maven.sh

```bash
#!/usr/bin/env bash

# === 配置部分 ===
MAVEN_VERSION="3.9.11"  # 你可以修改版本
INSTALL_DIR="$HOME/opt/maven"
MAVEN_URL="https://dlcdn.apache.org/maven/maven-3/${MAVEN_VERSION}/binaries/apache-maven-${MAVEN_VERSION}-bin.tar.gz"
PROFILE_FILE="$HOME/.bashrc"

# === 创建安装目录 ===
mkdir -p "$INSTALL_DIR"

# === 下载 Maven 压缩包 ===
echo "下载 Maven ${MAVEN_VERSION}..."
curl -fLo /tmp/apache-maven.tar.gz "$MAVEN_URL" || {
    echo "下载失败，请检查网络或版本号"
    exit 1
}

# === 解压到 INSTALL_DIR ===
echo "解压 Maven 到 $INSTALL_DIR ..."
tar -xzf /tmp/apache-maven.tar.gz -C "$INSTALL_DIR" --strip-components=1

# === 删除临时文件 ===
rm -f /tmp/apache-maven.tar.gz

# === 写入 ~/.bashrc ===
echo "配置环境变量..."
if ! grep -q "## Maven Environment Variables" "$PROFILE_FILE"; then
cat <<EOF >> "$PROFILE_FILE"

## Maven Environment Variables
export MAVEN_HOME="$INSTALL_DIR"
export PATH="\$MAVEN_HOME/bin:\$PATH"
EOF
    echo "已追加到 $PROFILE_FILE"
else
    echo "$PROFILE_FILE 已包含 Maven 配置，跳过追加"
fi

# === 提示刷新环境 ===
echo "安装完成！请运行以下命令刷新环境："
echo "source $PROFILE_FILE"
echo "验证版本：mvn -v"
```
