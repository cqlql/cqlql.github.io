

## 自旋 + sleep（不建议）

```java
while (!netClient.isConnected()) {
    if (System.currentTimeMillis() - startTime > timeout) {
        throw new IOException("WebSocket 连接超时");
    }
    Thread.sleep(100);
}
```

❗问题分析：

### 本质是“伪阻塞”

OkHttp 的 WebSocket 本身是**完全异步**的，你现在强行用 while + sleep 模拟同步效果：

- 轮询
- 线程空转
- 人工 timeout

这属于 busy-wait 的变体。

------

### 线程占用不优雅

- 当前线程被阻塞 10 秒
- 如果这是 WebSocket 回调线程或业务线程，可能影响吞吐
- 如果 future 要支持高并发连接，这种方式会放大问题

------

### 连接成功的时机不可靠

WebSocket 连接成功应该以：

```
onOpen(WebSocket webSocket, Response response)
```

为准。

而不是靠 `isConnected()` 轮询。

## 更优雅的方式：使用 CountDownLatch

这是标准做法。

1️⃣ NetClient 内部增加一个 latch

```
private final CountDownLatch connectLatch = new CountDownLatch(1);
private volatile boolean connected = false;
```

------

2️⃣ 在 onOpen 中释放

```
@Override
public void onOpen(WebSocket webSocket, Response response) {
    connected = true;
    connectLatch.countDown();
}
```

------

3️⃣ 提供 await 方法

```
public boolean awaitConnected(long timeout, TimeUnit unit)
        throws InterruptedException {
    return connectLatch.await(timeout, unit);
}
```

------

4️⃣ connectWebSocket 改造

```
netClient = new NetClient(Config.WS_URL, headers);

System.out.println("正在等待 WebSocket 连接建立...");

boolean success = netClient.awaitConnected(10, TimeUnit.SECONDS);

if (!success) {
    throw new IOException("WebSocket 连接超时");
}

System.out.println("WebSocket 连接成功，LogID: " + netClient.getLogid());

startConnection();
startSession();
```

------

🎯 优点

- 没有自旋
- 不浪费 CPU
- 不轮询
- 语义清晰
- 是并发标准写法
- 超时控制清晰

------

## 更高级做法：CompletableFuture

如果你想更现代一点：

```
private final CompletableFuture<Void> connectFuture = new CompletableFuture<>();
```

onOpen:

```
connectFuture.complete(null);
```

onFailure:

```
connectFuture.completeExceptionally(t);
```

等待：

```
connectFuture.get(10, TimeUnit.SECONDS);
```

优点：

- 可以传播异常
- 更现代
- 更优雅

### 不需要阻塞情况使用 orTimeout

```
readyFuture.orTimeout(15, TimeUnit.SECONDS)
        .thenAccept(v -> log.info("业务握手成功，Event 150 已收到"))
        .exceptionally(ex -> {
            log.error("会话启动响应处理失败: {}", ex.getMessage());
            this.close(); // 超时自动断开
            if (eventListener != null) {
                eventListener.onError(ex, null);
            }
            return null;
        });
```



------

## 🔥 总结

| 方式              | 是否推荐 | 适用场景 |
| ----------------- | -------- | -------- |
| while + sleep     | ❌ 不推荐 | demo     |
| CountDownLatch    | ✅ 推荐   | 生产     |
| CompletableFuture | ⭐ 更推荐 | 高级封装 |
