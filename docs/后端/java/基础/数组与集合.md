### 语法分类

Java 中创建数组主要有三种方式

| **方式**       | **语法示例**                    | **适用场景**                           |
| -------------- | ------------------------------- | -------------------------------------- |
| **静态初始化** | `String[] arr = {"A", "B"};`    | **已知具体元素**时使用，最简洁。       |
| **动态初始化** | `String[] arr = new String[2];` | **只知长度**，元素后续再赋值。         |
| **匿名数组**   | `new String[]{"A", "B"}`        | 用于**方法参数传递**，无需声明变量名。 |


匿名数组示例：

```
// 1. 分步赋值
String[] envs;
// 错误写法：
envs = {"dev", "local"}; // 编译失败
// 正确写法：
envs = new String[]{"dev", "local"};

// 2. 方法参数
// 错误写法：
// checkProfiles({ "dev", "local" }); 
// 正确写法：
checkProfiles(new String[] { "dev", "local" });
```

### 注解 vs 普通方法（数组写法区别）

| **特性**     | **在注解中 (@ActiveProfiles)** | **普通 Java 方法参数**           |
| ------------ | ------------------------------ | -------------------------------- |
| **单值**     | `"dev"` (自动转为数组)         | `new String[]{"dev"}`            |
| **多值**     | `{"dev", "local"}`             | `new String[]{ "dev", "local" }` |
| **类型检查** | 编译器根据注解定义自动识别     | 需要明确声明数组类型             |

### 内存模型 (Memory Visual)

当你写下 `String[] profiles = {"dev", "local"};` 时，底层发生了什么？

- **栈（Stack）**：存放引用变量 `profiles`，它像一个遥控器。
- **堆（Heap）**：实际开辟了一块连续空间，存放了两个字符串对象的地址。

### 常见坑点与最佳实践

- **长度固定**：数组一旦初始化，长度（`length`）就不可变了。如果需要动态增删，笔记里记得标注：*“请转看 ArrayList”*。
- **索引从 0 开始**：`profiles[0]` 是 `"dev"`，`profiles[1]` 是 `"local"`。
- **默认值**：如果是 `int[] arr = new int[2]`，里面默认存的是 `0`；如果是引用类型（如 `String`），默认存的是 `null`。
