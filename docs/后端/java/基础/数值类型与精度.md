# Java 所有数字类型完整对比

> 本文对 **Java 中所有常见数字类型**进行系统性对比，覆盖：
> - 基本类型 vs 包装类型
> - 整数 / 浮点 / 高精度 / 特殊用途
> - ORM / 数据库 / 金额 / 性能选型

---

## 一、整体分类速览

```
整数类型
├─ byte / Byte
├─ short / Short
├─ int / Integer
├─ long / Long
│
浮点类型（不精确）
├─ float / Float
├─ double / Double
│
高精度类型（精确）
├─ BigInteger
├─ BigDecimal
│
特殊用途
├─ AtomicInteger / AtomicLong
```

---

## 二、整数类型对比（最常用）

| 类型 | 字节 | 位数 | 取值范围 | 常见用途 | 推荐度 |
|----|----|----|----|----|----|
| byte | 1B | 8 | -128 ~ 127 | 状态位 | ⭐⭐⭐ |
| short | 2B | 16 | -3.2 万 | 几乎不用 | ⭐ |
| int | 4B | 32 | ±21 亿 | 默认整数 | ⭐⭐⭐⭐⭐ |
| long | 8B | 64 | ±9.22e18 | ID / 时间戳 | ⭐⭐⭐⭐⭐ |

### 选型建议
- **业务数字** → `int / Integer`
- **ID / 雪花算法 / 毫秒时间戳** → `long / Long`
- **状态字段** → `Byte`
- **Short 能不用就不用**

---

## 三、浮点类型（不推荐用于金额）

| 类型 | 字节 | 精度 | 特点 | 适用场景 |
|----|----|----|----|----|
| float | 4B | ~7 位 | 精度低 | 图形 / 科学 |
| double | 8B | ~15 位 | Java 默认 | 计算 / 统计 |

### ⚠️ 精度问题示例

```java
System.out.println(0.1 + 0.2); // 0.30000000000000004
```

👉 **永远不要用 float / double 表示金额**

---

## 四、高精度类型（金额 / 财务）

### 1️⃣ BigDecimal（最重要）

```java
BigDecimal price = new BigDecimal("19.99");
```

**特点**
- 任意精度
- 不会丢失小数
- 不可变对象

**正确创建方式**
```java
new BigDecimal("0.1");   // ✅
BigDecimal.valueOf(0.1); // ✅
new BigDecimal(0.1);     // ❌
```

**适用场景**
- 金额
- 财务
- 比例

---

### 2️⃣ BigInteger

```java
BigInteger n = new BigInteger("12345678901234567890");
```

**适用场景**
- 超大整数
- 密码学
- 特殊算法

## 六、ORM / 数据库选型建议（实战）

### 1️⃣ 实体类字段

```java
private Integer count;     // 推荐
private Long userId;       // 推荐
private BigDecimal amount; // 金额
```

### 2️⃣ MySQL 映射对照

| MySQL | Java 推荐 |
|-----|----------|
| TINYINT | Byte / Integer |
| SMALLINT | Integer |
| INT | Integer |
| BIGINT | Long |
| DECIMAL | BigDecimal |

**适用场景**

## 八、终极选型口诀（建议记住）

> 计数用 Integer，
> ID 用 Long，
> 金额用 BigDecimal，
> 计算用 Double，
> 状态用 Byte，
> Short 基本不用。

## 九、一句话总结

> Java 的数字类型并不复杂，
> **90% 的业务场景只需要：Integer / Long / BigDecimal**。
