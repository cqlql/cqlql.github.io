| **特性**           | **普通类 (Class)** | **抽象类 (Abstract Class)** | **接口 (Interface)**           |
| ------------------ | ------------------ | --------------------------- | ------------------------------ |
| **能实例化吗？**   | 能（直接 `new`）   | **不能**                    | **不能**                       |
| **有具体方法吗？** | 有                 | 可以有，也可以没有          | 以前没有，现在可以有 (default) |
| **有抽象方法吗？** | 没有               | **可以有**（强制子类实现）  | **全是**（默认都是抽象的）     |
| **主要目的**       | 代码复用           | **代码复用 + 强制规范**     | 纯粹的规范/契约                |
