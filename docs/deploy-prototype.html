常驻红线（与 docs/deploy.md §3 / §6 一致）
1. 不 down -v、不删 /data、默认不加 --remove-orphans； www 才用 --delete，secrets/ 不用且权限 600。
2. docker/.env 是 CRLF，同步必须转 LF；镜像引用逐字等于 compose 的 image: 前缀，远端注入 IMAGE_TAG。
3. Flyway 单向：只回滚镜像，不回滚数据库；回滚后起不来要如实说明，不许假装成功。
4. 私钥路径不打印；写动作必须显式二次确认 + 服务端预检门；预演不是执行凭证。

发布范围与只读预检 目标机名来自清单，不接受任意 host；预检不写远端

首次部署缺 /data / .env / secrets/ 时，预检必须 明确指出缺哪一项，不要开始构建；目标端口被非本栈容器占用、用户不在 docker 组同理。
